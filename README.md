# 参数化紧固件

参数化紧固件是面向 Rhino 8 Windows 与 FDM 3D 打印的 RhinoCommon 插件。它把螺丝、螺母、通孔、沉孔和咬合预孔保存为可编辑组件，并在“放入 Rhino”、STEP 或 STL 导出时才对宿主副本执行布尔，避免破坏原始 3DM 模型。

当前版本：`0.38.7`

## 0.38.7 更新常驻可用与快捷编辑操作栏

- 主面板“应用更新”始终可点击；点击时实时读取 Rhino 当前选择，无目标或异常目标只给出明确提示。
- 更新完成后保持控制点选中，可继续把当前面板模板应用到同一批组件。
- 快捷编辑窗口底部合并为 `读取｜取消｜应用｜删除` 单排操作栏。
- 删除按钮在浅色和深色主题下使用独立危险配色，首次点击后切换为高对比“确认删除”。

## 0.38.6 快捷窗口、操作面板与跟手预览

- 快捷编辑窗口的状态信息固定单行省略，窗口按真实内容高度布局，读取、删除、取消和应用按钮始终可见。
- “更多”操作面板固定在活动视口上方居中，并约束在当前显示器工作区内。
- 智能放置移动阶段只显示真实尺寸的紧固件本体，不再扫描轴向宿主或生成孔轮廓；点击时才执行完整识别与精确提交。
- 本体代理直接以局部缓存和显示变换绘制，取消每个鼠标位置重复复制、变换 Brep。

## 0.38.5 范围隔离导出、检查器处置与宿主识别增强

- Rhino、STEP、STL 与输出中心只校验本次所选宿主及其直接绑定；无关损坏组件不再阻断成果。
- 热熔螺母长度或深度补偿超过宿主时按完整截面贯穿并正常导出。
- 装配检查器可多选问题、选中/定位组件并一次 Undo 批量删除问题组件。
- 轴向区间改用实体内外配对与接缝微偏移多数判定；必要时可点击确认咬合宿主并持续保存。

## 0.38.4 Yak 首次启动激活修复

- Yak成为正式安装、版本切换和插件注册的唯一来源；离线安装器不再额外写入Rhino简略注册。
- 升级时只清理0.38.3遗留且明确指向Yak目录的根项`FileName`，完整注册、命令清单和用户设置全部保留。
- 诊断工具同时检查根项、`PlugIn\FileName`、命令清单、禁用状态、依赖、下载阻止标记和.NET运行时。
- 安装后完全启动Rhino一次即可使用，不再需要手动加载或第二次重启。

## 0.38.0 智能装配加速

- 修复停靠面板、多视口及高 DPI 环境下自由面放置射线偏移的问题。
- 点集批量放置支持点、点云、曲线端点、圆/圆弧中心、圆形 Brep 边及选中平面内圆环。
- 每个点位独立测量宿主并给出可解释的长度建议，可下拉选择或直接输入采用长度。
- 同一批次保持统一装配方式；只有所有点位支持同一替代方式时才允许整批切换。
- 多选浮动条支持“长度自适应”，按各组件宿主厚度分别计算长度后一次 Undo 更新。
- 收藏模板可升级为装配方案，保存模板优先策略和自适应长度选项。

## 0.37.3 只咬合顶部对位孔

- “只咬合”装配新增顶部正补偿对位段，默认深度 `3.00 mm`、直径正补偿 `0.20 mm`。
- 对位段与原咬合孔通过夹角 `60°` 的直线圆台连接；深度设为 `0` 可完全关闭，旧组件保持关闭。
- 倾斜或曲面宿主按完整对位孔圆周的最深入口计算直段深度，预览、组件和 Rhino/STEP/STL 输出共用同一几何结果。

## 0.37.2 智能放置性能优化

- 智能放置采用“移动时轻量预览、点击时精确生成”：悬停不再构建完整切割 Brep，也不执行布尔预检。
- 命令启动时建立宿主 RTree，Extrusion 仅转换一次；前表面拾取改为宿主级精确求交，轴向识别只检查有限线段附近候选。
- 虚拟紧固件仍按真实尺寸显示，通孔、咬合孔、沉孔、安装槽、倒角和架桥以轻量轮廓或短标签表达。
- 鼠标输入以约 33 ms 合并消费，动态绘制只读取已有结果；面板参数变化仍会主动刷新预览。
- 单击后只执行一次完整几何准备，并将准备结果直接提交，避免同一位置重复建模；参数或宿主变化时零写入并要求再次确认。

## 0.37.1 快捷编辑精简

- 单选控制点后的快捷编辑条只保留参数修改、读取、删除、应用和取消，减少低频按钮干扰。
- 参数手柄与装配检查继续由主面板、“更多…”和公开命令提供；复制继续使用 Rhino 标准 Copy。
- 智能摆放统一采用宿主面法线朝内方向，不再提供手动翻转覆盖；复杂方向使用经典放置明确指定轴向。
- 插件按需剖切及其视口显示管线已移除，多选条聚焦模板应用、检查和维护。
- 主面板顶部明确区分“创建模板”和“选择目标”，场景选择不覆盖模板，只有“读取到模板”会载入组件参数。
- “更多…”改为支持搜索和键盘操作的分组操作面板。

## 0.36.3 双模式咬合孔入口倒角

- 咬合孔入口倒角新增“轴向45°”与“表面等距”两种模式，开启后可在同一个 C 参数下直接切换。
- 轴向45°继续支持平面和连续曲面入口，并保持 0.36.2 的几何结果不变。
- 表面等距从实际布尔孔口识别完整平面边环，令宿主表面与孔壁各退让 C，适合倾斜平面上的标准等距倒角。
- 曲面、跨非共面入口、边缘材料不足或候选不唯一时，表面等距会在写入前停止并提示改用轴向45°。
- 智能预览、组件代理、一键修复和 Rhino/STEP/STL 导出共用同一宿主专属切割体。

## 0.36.2 倾斜咬合孔倒角修复

- 倾斜平面入口改用 45° 锥体与实际入口面的解析交线，不再反复放大统一探测圆。
- 曲面和跨面入口改为逐方向有界求根；每个方向都必须得到唯一入口区间，避免生成残缺锥口。
- 螺丝轴相对入口法线小于 45° 时，浅侧倒角自然变宽、最深侧仍不少于设定 C 值；达到或超过 45° 时显示明确的物理限制。
- 智能预览、组件代理、一键修复与 Rhino/STEP/STL 导出继续共用同一倒角几何。

## 0.36.1 咬合孔入口直线倒角

- “螺纹咬合”装配方式新增可选的 45° 咬合孔导入口，默认关闭、默认预设 `C0.50 mm`。
- 倒角以最终咬合孔直径为小端，垂直入口的大端直径为“最终孔径 + 2C”，不会改变盲孔孔底。
- 倾斜和曲面入口按完整锥口圆周计算最早/最晚入口，保证最深侧至少达到设定 C 值；近切向、重叠入口和厚度不足会在写入前停止。
- 智能预览、组件代理、一键修复及 Rhino/STEP/STL 导出复用同一份倒角几何。

## 0.36.0 可靠内核与文档自愈

- 控制点 JSON 成为组件参数的唯一持久化事实；控制点实际坐标优先保留用户完成的移动，本体、切割体和组均可重新生成。
- 放置、更新、修复、预览和导出共用不可变组件快照、规格解析、几何准备及参数/几何签名，避免预览、文档对象和 Rhino/STEP/STL 结果分叉。
- 批量写入先完成全部预检，再暂存新对象并一次提交；内部变更日志在异常时恢复对象、属性、组和材质，防止留下半个组件。
- 文档打开后在 Idle 阶段增量执行只读健康扫描，仅在发现“需重建、待重绑或损坏”时提示；打开文档不会自动修改模型。
- “一键修复”只重建宿主明确的确定性问题；待重绑组件继续由用户确认，损坏组件不会被代理体旧数据猜测恢复。

## 0.35.5 持久安装与重启自修复

- 正式发布改为 Rhino Yak 离线安装包，插件安装到当前用户的稳定包目录，移动下载文件或删除解压目录不再导致重启失效。
- 插件改为 Rhino 启动时加载，并在首次 Idle 后按固定 RUI GUID 修复旧工具栏路径；已加载的正确工具栏不会被重复关闭或打开。
- “关于参数化紧固件”可查看实际 RHP、工具栏路径、Yak/手动安装方式与安装健康状态。
- `artifacts/plugin` 继续服务本机开发调试，正式用户只使用 `artifacts/packages` 中的离线安装 ZIP。

## 后续发展路线

可靠内核阶段已经完成，后续将通过两个体验阶段进入 1.0 稳定版：

- `0.36`（已完成）：统一组件快照、几何准备与事务，增加非破坏文档健康检查和安全自愈。
- `0.37`（已完成）：收敛主面板与上下文编辑；0.37.2进一步精简入口并将智能放置改为轻量预览、精确提交。
- `0.38`：增加可确认的装配建议、重复位置识别和按宿主自适应的批量更新。
- `1.0`：冻结核心行为，完成固定回归模型、支持矩阵和稳定发布。

路线优先解决稳定性、操作理解和个人建模效率，不计划真实螺纹、承载计算、打印机校准、云端社区或无确认自动修改。完整内容见[未来发展路线](docs/FUTURE_DEVELOPMENT_ROADMAP.md)。

## 0.35.4 螺丝头离面间隙

- 三类螺丝的“嵌入/离面”允许输入负值；例如 `-2 mm` 会让整颗螺丝向外移动，使头底距离宿主表面 `2 mm`。
- 控制点始终保留在原放置面，螺杆有效进入长度、宿主识别、咬合孔深和配套螺母位置同步采用实际偏移。
- 偏移为零或负值时不生成沉孔、沉头承座或头部通道，杯头悬垂架桥同步关闭。
- 六角螺母仍只允许非负嵌入；离面距离达到螺杆长度时会阻止操作并给出明确提示。

## 0.35.3 装配检查器可选长度

- 装配检查器的长度建议行新增“采用长度 mm”：可从常用值、当前值和建议值中选择，也可直接输入 `0–1000 mm` 的自定义长度。
- 修改后的行会进入待应用队列；“应用长度（N）”可一次更新多颗螺丝，并共用一次 Undo。
- 应用前重新读取组件并执行完整几何预检；任一组件失败时整批零写入，模型变化后则必须重新检查。
- 应用成功后自动重新运行检查，继续显示仍未解决的长度或装配问题。

## 0.35.2 操作入口与主题统一

- “读取组件”移入快速小窗，并在“更多…”菜单保留备用入口；主面板高频操作更聚焦。
- 主面板与 Rhino 工具栏统一为放置、更新、维护、Rhino、STEP、统计、装配检查、更多八项操作。
- 独立窗口统一采用 Rhino 原生浅色/深色主题，运行时切换主题同步刷新。
- “更多…”新增关于窗口，可查看并复制插件、Rhino 与数据 schema 版本信息。

## 0.35.1 框选后直接更新

- 单选或框选控制点后，修改面板规格、长度、孔深、补偿或装配参数即可直接点击“更新”，无需先运行刷新。
- 更新按钮始终依据 Rhino 当前真实选择同步；代理体转选、取消选择和批量选择均会即时刷新目标状态。
- 选择仍只指定更新目标，不会覆盖面板模板；“读取组件”仍是载入现有组件参数的唯一入口。
- 损坏或待重新绑定组件继续阻止批量更新，事务预检失败时保持零写入。

## 0.35 全插件视觉与交互统一

- 主面板、导航器和独立窗口共用 Rhino 深浅色主题、4/8/12 DIP 间距与固定摘要/弹性内容/固定操作栏骨架。
- 装配检查器改为每文档单一非模态窗口；模型变化后结果自动标记过期，重新检查前不能采用旧建议。
- 批量预检、导航器深度检查、重绑候选和输出中心显示阶段、数量与进度，并可在安全步骤边界取消。
- 更新、刷新、重绑和批量放置成功后显示短暂视口定位反馈；不使用持续动画或额外文档对象。
- 自定义标准件库在宽窗口使用双栏，窄窗口自动变为定义列表与单栏编辑；长文本通过详情和 Tooltip 展示。
- 组件 schema 继续保持 v17，现有模型、几何、命令和导出结果不迁移。

## 0.34 交付能力

- 装配检查器在输出前检查宿主、参数、布尔、长度、意外碰撞、薄壁、孔距和基本工具空间，并提供可显式采用的长度建议。
- 维护中心将快速刷新、显式重新绑定和残留清理拆分为三个安全动作。
- 输出中心使用同一不可变快照，原子生成 Rhino 3DM、STEP、STL、Excel 和 CSV；任一格式失败时不保留半套交付文件。
- 组件支持装配编号、项目分组和用户备注，并随复制、粘贴及 3DM 传递。
- 自定义标准件库 Beta 从内置规格复制创建，支持 JSON/CSV 交换；组件保存完整尺寸快照，跨电脑缺少用户库时仍可编辑和导出。

## 主要功能

- 支持 M1.6、M2、M2.5、M3、M4、M5、M6、M8、M10、M12 常用规格。
- 支持内六角杯头螺丝、内六角沉头螺钉、六角头螺栓、普通六角螺母、尼龙防松螺母和自定义尺寸热熔螺母。
- 杯头、沉头和六角头螺丝支持正值嵌入、零值贴面及负值离面间隙；控制点保持在安装面，全部几何与导出使用同一实际轴向位置。
- 六角螺母页面通过“尼龙防松螺母”复选框在普通与防松样式之间切换。尼龙防松螺母 M3–M12 使用 GB/T 889.1-2015 兼容外包络，M2、M2.5 为明确标注的 DIN 985 工程扩展预设；M1.6 在防松模式下禁用。
- 六角螺母使用带打印补偿的六角盲槽，并支持 `0`、全埋和任意非负自定义嵌入深度；热熔螺母使用可设置长度、外径、孔径补偿和深度补偿的 45° 导角安装孔，新建时默认增加 1 mm 切割深度。
- 六角螺母和热熔螺母单击封闭宿主面即可完成位置、方向、宿主绑定和创建。
- 热熔螺母安装孔允许穿透宿主；本体长度或深度补偿超过宿主时会提示贯穿，但仍可放置、更新并导出。贯穿范围按完整入口圆截面计算，适配倾斜和曲面背面。
- 通过控制点读取、更新、批量更新和删除紧固件组件。
- 面板采用“参数模板 + 选择目标”：框选控制点只更新顶部选择摘要，不覆盖面板参数；快速小窗“读取”或“更多…”中的备用读取入口才会载入已有组件数据。
- 单选有效控制点约 250 ms 后自动显示紧凑视口快速编辑器，标题显示 `杯头 M3X20`、`防松螺母 M5` 等短类型与核心规格；底部提供“读取、确定、取消”，主面板“快速小窗”开关可随时关闭自动弹出。
- Rhino右侧停靠栏使用独立的多分辨率参数化紧固件图标，在浅色和深色界面中均保持清晰。
- 快速编辑小窗默认位于控制点右下方 36×40 DIP，并在视口边缘自动回退，避免遮挡控制点和 Gumball。
- 参数手柄提供长度、嵌入深度、螺母末端露出量和方向旋转的显式点击编辑；手柄修改复用组件事务预检，并支持常用长度、0/齐平、0/2 mm 和 15° 吸附。
- 主面板摘要下方提供紧凑模板栏，保存最近 5 个成功操作和最多 50 个收藏模板；收藏可重命名、复制、排序以及导入/导出 JSON，并跨文档、跨 Rhino 会话保留。
- 支持“重复上一放置”和“重复上一更新”，使用最近一次成功操作的不可变快照，不覆盖当前主面板模板。
- 单颗螺丝的选择摘要使用“杯头 M3*30 +1切割 通1/咬1”式紧凑格式；底部八项为放置、更新、维护、放入 Rhino、STEP、统计、装配检查、更多，并在同一 Rhino 主题下保持统一颜色和按钮背景。
- 读取组件会原子同步类别卡片和专属参数布局，可在螺丝、六角螺母与热熔螺母之间可靠切换。
- 类型、规格、长度、嵌入、补偿和咬合孔深度可作为统一模板，一次应用到多个控制点；更新后模板保持不变，便于连续处理多批组件。
- 螺丝装配方式统一为“螺纹咬合、只咬合、螺母固定”三种模式；一颗螺丝可绑定多个宿主。
- “螺母固定”让所有宿主使用 `D + 孔径修正` 的正补偿通孔，并在螺杆末端生成普通或尼龙防松配套螺母；末端露出量默认 2 mm，贯穿六角槽拥有独立补偿。
- 螺丝可开启严格“只咬合”加强筋模式：仅绑定放置面宿主，不生成穿过体；宿主无法完整容纳螺杆或螺杆范围内存在第二实体时停止生成并给出可用最大长度。
- “只咬合”导出会在内存中重新复核唯一宿主，并沿用咬合模块的预览/布尔设置；0.26.0–0.26.1 已保存的异常组件会在读取时自动修复，不再因原通孔开关关闭而漏切螺丝孔。
- 孔径按公称直径独立计算：通孔为 `D + 孔径修正`，咬合孔为 `D − 咬合缩减`；目标附加修正最后叠加，旧通孔配合字段仅用于兼容历史组件。
- 智能自动摆放要求螺杆完整穿出第一宿主并进入后方咬合宿主；单宿主加强用途请开启“只咬合”。
- 所有孔入口均按整个孔圆柱与宿主的实际覆盖范围切入；通孔及完全贯穿咬合孔的出口也使用完整范围，倾斜或曲面表面不会留下楔形薄层。
- 咬合孔支持完全贯穿、螺杆长度 + 1D，以及螺杆长度 + 自定毫米增量；新建螺丝默认使用 L+1D。
- 孔深、预览和导出布尔集中在“孔与切割”区域统一控制，不再显示重复的宿主切割模块卡片。
- 支持螺丝头嵌入深度，提供 0 和齐平快捷设置。
- 杯头沉孔可选“双层交叉架桥”补偿：第一层保留切线桥、第二层生成垂直桥，再恢复圆形螺杆孔；默认关闭，每层默认 0.20 mm，可匹配实际切片层高。
- 默认使用智能所见即所得放置：虚拟紧固件跟随鼠标，实时预览本体、切割体和宿主角色；无捕捉点时落在鼠标所在面，有端点、中点、圆心、交点、节点或 Point 时优先精确捕捉。
- 支持点集批量放置：选择 Rhino Point、点云、开放曲线端点或圆/圆弧中心，使用当前不可变模板逐点严格匹配实体面并预检；默认全有或全无，也可明确跳过失败点后一次创建。
- 点集批量放置预检采用固定摘要、弹性表格和固定操作栏；少量点位自动压缩窗口，大批量数据只在表格中纵向滚动，并完整适配 Rhino 深浅色主题。
- 主面板“放置”左击继续智能连续放置，右击进入点集批量放置；RUI 工具列保持相同左右键语义。
- 智能放置沿螺杆轴线自动识别穿过体与咬合体：单宿主默认为咬合体，多宿主时最深处为咬合体、其余为穿过体；经典手动绑定流程继续保留。
- 新建智能组件在修改螺杆长度后会重新扫描有效轴向范围，自动新增或移除宿主，并重新划分穿过体与咬合体；经典放置及旧组件保持手工绑定。
- 支持整体移动、复制、打组移动/复制、Gumball Alt 复制、Ctrl+C/V、跨文档粘贴和 3DM 导入后的组件修复。
- 支持放入 Rhino、导出 STEP、导出 STL、紧固件统计和 Excel 清单；一套螺丝＋螺母装配在物料统计中展开为一颗螺丝和一颗螺母。
- 增加“紧固件导航器”停靠面板，可按类型、规格、装配方式、宿主、图层和健康状态筛选组件；单击定位、双击缩放，并可对筛选结果执行选择、模板更新、统计和导出。
- 导航器的问题中心即时汇总待重绑、参数无效、预览隐藏和导出关闭；“深度检查”才在内存中执行真实布尔验证，可随时取消且不会修改模型。
- 文档级 RTree 宿主索引统一服务智能预览、严格点位匹配和轴向宿主识别；对象变化、Undo/Redo 和文档切换后自动失效并按需重建。
- “放入 Rhino”图标左击只输出布尔宿主，右击同时输出关联紧固件实体；钢制紧固件与热熔螺母自动使用共享的拉丝钢或黄铜 PBR 材质，并放入独立渲染图层。
- 主面板取消“使用说明”和内嵌显示设置；通过“更多 → 全局显示…”在独立窗口实时预览全部组件透明度，确定保存、取消恢复。
- 全部参数化组件复用文档级本体/切割显示材质；复制、粘贴和导入不会再为每颗副本新增材质或贴图资源。
- 热熔螺母界面使用紧凑孔径/深度摘要，完整计算公式通过悬停提示查看，窄面板不再出现横向滚动条。
- 面板按 280–500 DIP 实际可用宽度分级排列；追加孔深独立成行，只咬合时隐藏无关通孔模块，降低横向占用和纵向滚动距离。
- 面板和紧固件统计窗口自动跟随 Rhino 浅色/深色主题，并在 Rhino 运行期间切换主题时即时更新。
- 深色模式使用分层卡片、高对比状态色和独立浅色线性图标，输入框、下拉框和滚动条继续采用 Rhino 原生样式。
- 保留旧 `RhinoMM*` 命令和 `RhinoMM.*` 元数据键，兼容已有模型。

## 安装

1. 下载并完整解压 `参数化紧固件-0.38.7-离线安装.zip`。
2. 保存工作并完全关闭 Rhino 8。
3. 双击 `安装参数化紧固件.cmd`。
4. 安装成功后启动 Rhino 8，运行 `ParametricFasteners`。
5. 在“更多 → 关于参数化紧固件”确认安装方式为 `Yak`、状态为“安装正常”。

离线安装不需要网络或管理员权限。也可以在 Rhino 的 Package Manager 中选择 Yak 文件安装，但安装后必须完全关闭并重新启动 Rhino。请勿从压缩包临时目录、U 盘或之后会移动的目录直接选择 RHP；直接 RHP 仅用于开发调试。若重启后命令仍不可用，请运行离线包中的`诊断安装.cmd`。详细说明见 [离线安装说明](packaging/安装说明.md)。

如果 Rhino 曾通过 `SetDotNetRuntime` 切换到 `NETFramework`，请改回 `NETCore` 并重启 Rhino。

## 构建

要求：

- Windows
- Rhino 8.18 或更新版本
- .NET SDK，仓库通过 `global.json` 固定 SDK 版本

构建命令：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./build/build.ps1 -Configuration Release
```

构建脚本会执行核心测试、Release 构建、工具列生成、兼容性检查和开发目录原位部署，同时原子生成 `artifacts/packages/` 中的 Yak 与离线安装 ZIP。部署前会把旧插件目录备份到 `artifacts/backups/<timestamp>-<version>/`。如果 Rhino 正在占用插件文件，脚本会停止并提示关闭 Rhino，不会覆盖当前插件。

## 数据与精度说明

普通紧固件预设仍以 ISO 等效工程尺寸为主，不能整体宣称“已通过国标核验”。尼龙防松螺母 M3–M12 使用 GB/T 889.1-2015 兼容外包络；M2、M2.5 仅为 DIN 985 工程扩展，必须核对实际采购件。直接咬合预孔不是标准内螺纹，实际保持力依赖材料、层高、打印方向、螺丝和打印机校准，应通过试片验证后用于生产。
