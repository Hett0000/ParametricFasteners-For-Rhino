# 参数化紧固件 0.30.2

## 热熔螺母贯穿导出

- 热熔螺母安装孔允许穿透宿主；螺母本体长度或深度补偿超过宿主时改为警告，不再阻止放置、更新或导出。
- 贯穿切割按入口最大直径计算完整圆形截面覆盖范围，倾斜、曲面和楔形背面不会残留薄层。
- 智能预览、组件更新、放入 Rhino、STEP 与 STL 共用同一切割计算。

## 快速编辑器与工具栏

- 快速编辑小窗相对控制点向右 36 DIP、向下 40 DIP，并继续约束在活动视口内。
- Rhino 工具栏统一为：读取、放置、更新、刷新、放入 Rhino、STEP、统计、更多。
- “放入 Rhino”左击只输出布尔宿主，右击同时输出关联紧固件实体。
- 工具栏“更多”打开主面板中的同一菜单；转换、校验和 STL 等低频操作继续保留。

组件 schema 继续使用 v16，现有模型无需迁移。
