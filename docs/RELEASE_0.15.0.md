# 参数化紧固件 0.15.0

## 安全移动与复制

- Move、Copy、用户组移动/复制以及 Gumball Alt 平移复制统一进入组件生命周期事务。
- 副本生成独立组件 ID、绑定 ID和对象 ID；原组件及其宿主保持不变。
- 隐藏切割体未进入 Rhino 选择集时仍会根据控制点中的参数完整重建。
- 宿主和组件一起复制时自动关联复制后的宿主；只移动或复制组件时在新位置执行唯一宿主匹配。
- 保留用户外部 Rhino Group，并为副本重新创建独立的内部组件组。

## 粘贴、导入与待重绑

- 支持同文档 Ctrl+C/V、跨文档粘贴以及包含参数化组件的 3DM Import。
- 无法唯一匹配宿主时保留独立控制点和代理体，绑定目标置空并提示运行“刷新 / 清理”。
- 待重绑组件禁止应用更新和布尔导出，避免静默漏切。
- “刷新 / 清理”显示待重绑数量，并在用户选中对应宿主后重建完整切割模块。

## 兼容性

- 组件 schema 保持 v5。
- 插件 GUID、`RhinoMM.*` 元数据键、旧命令和已有 3DM 文件保持兼容。
