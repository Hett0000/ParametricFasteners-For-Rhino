# 参数化紧固件 0.35.3

## 装配检查器可选长度

- 问题表格新增“采用长度 mm”列，仅在带有长度建议的问题行中启用。
- 下拉选项包含常用长度、组件当前长度和检查器建议长度，并按数值排序、去重。
- 支持直接输入大于 `0` 且不超过 `1000 mm` 的自定义数值，界面最多显示两位小数。
- 恢复当前长度会自动取消待应用状态；详情区同步显示当前、建议、采用和差值。
- “应用长度（N）”一次提交全部待应用组件，并只产生一个 Undo 记录。

## 安全与一致性

- 应用时按组件 ID 去重，并从 Rhino 文档重新读取最新组件数据，只覆盖螺丝长度。
- 全部组件复用现有更新协调器，统一执行智能宿主重识别、本体与切割体重建及几何预检。
- 任一组件损坏、待重绑、输入非法或预检失败时整批零写入。
- 模型变化后检查结果标记过期，长度编辑与应用立即禁用；重新检查后按最新长度初始化。
- 更新成功后自动重新运行装配检查，便于继续处理仍存在的问题。

## 兼容性

- 插件版本升级为 `0.35.3`。
- 组件 schema 保持 v17；模板 schema v2、用户库 schema v1 均不变化。
- 不修改既有组件 GUID、宿主绑定、孔参数、导出规则或 3DM 数据。
