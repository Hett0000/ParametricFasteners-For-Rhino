# 参数化紧固件 0.28.2

## 六角螺母防松入口修复

- 类型区继续只显示“六角螺母”，进入六角螺母参数页后可直接勾选“尼龙防松螺母”。
- 读取普通六角螺母或尼龙防松螺母时，复选框会与组件数据同步，不会改变普通场景选择所使用的面板模板。
- 勾选防松后自动禁用 M1.6；当前为 M1.6 时切换至 M2。M2、M2.5 继续标记为 DIN 985 工程扩展，M3–M12 使用 GB/T 889.1-2015 兼容尺寸。
- 普通与防松样式切换时，零嵌入和自定义嵌入深度保持不变；全埋状态自动匹配新样式总高。
- 组件 schema 保持 v15，既有几何、导出、统计及 Excel 数据兼容。
