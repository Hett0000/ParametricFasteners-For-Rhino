# 产品与技术决策记录

## 已确认决策

| 编号 | 决策 | 理由 |
| --- | --- | --- |
| D-001 | 首版目标为 Rhino 8 Windows | 降低首版运行时和测试矩阵复杂度 |
| D-002 | 使用 .NET 8、RhinoCommon、Eto | 对齐 Rhino 8.20+ 默认运行时和跨平台 UI 框架 |
| D-003 | 孔组件非破坏式保存 | 允许持续修改规格、位置和补偿 |
| D-004 | 导出时在副本上布尔 | 确保 3DM 原模型不变并避免漏切 |
| D-005 | 首版不生成真实螺纹 | 提高 FDM 适用性、性能和布尔稳定性 |
| D-006 | 首版支持封闭 Brep/Extrusion | 保证 STEP/STL 几何管线稳定；Mesh/SubD 延后 |
| D-007 | 支持平面和曲面法向放置 | 覆盖实际机械外壳和自由曲面使用场景 |
| D-008 | 孔组件显式绑定宿主 | 避免空间相交自动判断导致误切 |
| D-009 | 全局打印配置＋单组件覆盖 | 同时支持批量一致性和局部校准 |
| D-010 | 首版四类预设、M2–M12 | 覆盖常用场景并控制标准数据验证成本 |
| D-011 | 使用 ISO 等效公开尺寸并明确标记 | 在缺少授权 GB 尺寸表时保持数据可追溯且不夸大合规性 |
| D-012 | 失败时取消整个导出 | 不产生看似成功但缺孔的打印文件 |
| D-013 | 默认输出毫米 | 符合常见 FDM 切片流程；STL 额外提示其无单位元数据 |

## 视觉建议，待产品评审确认

以“参数检查器”作为 MVP 主框架，加入非强制实时检查和轻量画布上下文操作。三套原始草图均保留在 [产品草图](PRODUCT_SKETCHES.md) 中，方便评审时比较。

## 延后决策

- Rhino 9 与 macOS 支持策略。
- Mesh/SubD 宿主的转换或独立布尔实现。
- 侧向插入螺母槽和热熔螺母预设。
- 真实打印校准向导与社区预设分享。
- 经授权的 GB 尺寸库切换和合规声明流程。
