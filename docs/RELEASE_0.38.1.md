# 参数化紧固件 0.38.1

## 智能放置拾取坐标热修复

- 修复停靠面板、多视口、浮动视口及高 DPI 环境中无法智能放置的问题。
- `GetPointMouseEventArgs.WindowPoint`现在直接按当前视口客户端坐标处理，不再重复转换为桌面屏幕坐标。
- 拾取射线统一按摄像机方向调整为近裁剪面到远裁剪面，继续优先选择鼠标下方最前面的封闭实体。
- 保留精确 Brep 求交、深度重合歧义检测和点击前二次校验。
- 拾取坐标异常时在 Rhino 命令行输出限频诊断，便于定位视口和 DPI 问题。
