# 参数化紧固件 0.6.0

## 本版重点

- 沉头螺钉和头部切割体统一使用正确方向的截锥，大端朝外，小端连接螺杆。
- 通孔宿主和咬合宿主默认单击完成；命令行可切换“多选”后连续选取。
- 规格改为 M1.6–M12 卡片，长度增加 8、10、12、15、20、25、30 mm 快捷卡片和自定义输入。
- 本体和切割模块不再使用 Rhino 锁定显示，文档材质和渲染材质保持同步。
- 点击或框选插件几何会自动转选对应控制点。
- 底部新增“刷新 / 清理”，在一次 Undo 中删除所有已丢失有效控制点的紧固件组件，不修改宿主。

## 数据兼容

持久化 schema 升级到 v5。v1–v4 数据可读取；v4 沉头螺钉的旧齐平值会迁移为新截锥头高，其他手动嵌入值保持不变。插件 GUID、组件 ID、宿主绑定及 `RhinoMM.*` 键保持兼容。
