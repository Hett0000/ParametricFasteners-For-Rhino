# 参数化紧固件 0.38.0

## 智能装配加速与放置拾取修复

本版本修复了 0.37.3 中自由面智能放置可能提示“候选封闭实体未相交”的阻断问题，并将宿主测量、长度建议、批量预检和装配检查统一到同一套可确认流程。

### 主要变化

- 新增统一视口拾取射线服务，正确处理停靠面板、多视口、浮动视口和 Windows 高 DPI 坐标。
- 前表面选择使用 RTree 预筛选和精确 Curve/Brep 相交，点击提交时再次执行相同检测。
- 新增 `AssemblyMeasurementSnapshot`、`AssemblySuggestion` 与共享建议计算器。
- 批量放置支持 Point、点云、圆/圆弧、开放曲线端点、圆形 Brep 边和平面圆孔内环。
- 批量预检新增当前、建议和采用长度；支持常用长度下拉、自定义输入、全部采用建议和恢复模板长度。
- 当前装配方式优先；只有全部点位支持同一种替代方式时才允许整批切换并重新预检。
- 多选浮动条新增长度按宿主自适应更新，一次 Undo 提交整批结果。
- 装配检查器使用同一测量与建议服务，避免出现不同入口给出矛盾长度。
- 收藏模板库升级到 schema v2，可为收藏项保存装配方案和自适应长度策略。

### 数据与兼容

- 插件版本：`0.38.0`
- 组件 schema：`v20`（不变）
- 模板 schema：`v5`（不变）
- 模板库 schema：`v2`
- 旧收藏自动作为普通模板读取，不自动开启自适应或覆盖输出设置。

### 安全规则

- 智能结果只作为建议，必须经过预检窗口确认。
- 同一批次装配方式一致，仅长度允许按位置独立变化。
- 提交前重新验证文档、宿主、参数和采用长度；任一失败则零写入。
