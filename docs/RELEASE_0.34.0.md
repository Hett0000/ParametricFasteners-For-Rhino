# 参数化紧固件 0.34.0 发布说明

0.34.0 将原 Roadmap 的 0.33「装配可靠性」与 0.34「交付与受控扩展」合并交付。主面板和底部八项高频操作保持不变，新能力集中在“更多…”、组件导航器和独立窗口中。

## 装配可靠性

- 新增装配检查器，检查丢失宿主、非法参数、真实布尔失败、装配长度、非预期实体碰撞、孔边余量、相邻孔间隔和基本工具操作空间。
- 默认检查阈值为：壁厚 0.80 mm、孔间实体 0.80 mm、工具径向余量 2.00 mm、工具轴向空间 10.00 mm；设置按用户跨会话保存，不写入组件。
- 螺纹咬合、只咬合和螺母固定分别提供常用长度建议；没有合适常用长度时按 0.5 mm 给出自定义建议。只有点击“采用建议”才修改模型。
- 原“刷新/清理”升级为维护中心：快速刷新不猜测宿主；重新绑定显示候选轴线区间、切割体重叠与评分原因；清理只删除缺少真实控制点的残留。

## 输出中心与 BOM

- 输出范围支持当前选择、指定多个图层和全部有效宿主。
- 一次可生成 3DM、STEP、STL、Excel、CSV；新安装默认选择 STEP + Excel。
- 全部格式共用同一组件、宿主和布尔结果快照。输出先写入临时目录，全部成功后再原子改名为 `<项目名>_交付_yyyyMMdd-HHmm`。
- 3DM 和 STEP 可包含独立图层与材质的紧固件渲染实体；STL始终只包含可打印的布尔宿主。
- 组件新增装配编号、项目分组和用户备注。Excel/CSV 同时输出宿主名称、宿主图层和装配角色；螺母固定组件仍按一颗螺丝加一颗配套螺母展开。

## 自定义标准件库 Beta

- 用户定义必须从现有内置类型和规格复制，不能引入脚本、任意几何生成器或新的装配语义。
- 可编辑现有类型所需尺寸、名称、来源、修订和备注，并在保存/导入前校验尺寸完整性与基本几何关系。
- 支持 JSON 完整交换和 CSV 尺寸表交换；同 ID 同内容跳过，冲突定义生成新 ID 和导入名称，不静默覆盖。
- 自定义组件保存定义 ID、名称和完整尺寸快照。尺寸快照是几何权威数据；另一台电脑没有用户库时，模型仍能读取、更新和导出。
- 修改用户库不会静默改变已有组件，必须使用“所选组件使用最新版”显式升级。
- 用户库损坏时原始 JSON 被备份，插件回退为空用户库；内置库和已有组件不受影响。

## 数据与兼容

- 插件版本升级为 `0.34.0`。
- 组件 schema 升级为 v17，新增 `DeliveryMetadata` 和自定义定义尺寸快照。
- 模板 schema 升级为 v2，收藏与重复操作可携带自定义定义快照。
- v16 及更早组件迁移后交付信息和自定义定义为空，原有几何、宿主、组件 ID 与绑定 ID 保持不变。
- 插件 GUID、`RhinoMM.*` 元数据键、旧命令和现有快捷导出保持兼容。
