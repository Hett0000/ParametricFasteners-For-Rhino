# 参数化紧固件 0.14.0

## 可靠布尔导出

- Rhino、STEP 和 STL 导出不再读取视口预览切割体的几何或旧组件 JSON。
- 导出以有效控制点保存的组件数据为唯一参数来源，并通过共享切割服务实时生成轴孔和头部切割体。
- 预览切割体缺失、隐藏或保存旧参数时仍可正确导出；缺少控制点或宿主绑定失效时停止并提示运行“刷新 / 清理”。
- 所选宿主没有启用的切割模块时保留原几何并给出警告。
- 面板导出前使用几何参数签名检测未应用草稿，不再只依赖界面脏标志，也不会因透明度和预览变化重建几何。

## 放置切割预设

- 面板增加独立的“放置切割预设”，支持孔径修正、通孔配合、咬合缩减、咬合深度、自定义深度、预览和导出布尔开关。
- 新组件默认使用“螺杆长度 + 2D”；通孔仍固定贯穿宿主。
- 预设通过 Rhino 插件设置跨会话保存，未知、损坏或越界设置自动回退到安全默认值。
- 单次选面和连续捕捉点放置使用相同预设；读取和编辑旧组件不会覆盖全局放置预设。

## 兼容性

- 版本升级为 0.14.0，持久化 schema 保持 v5。
- 既有组件的孔深、绑定、组件 ID和旧命令保持不变。
