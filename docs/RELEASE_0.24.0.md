# 参数化紧固件 0.24.0

## 读取修复

- 修复热熔螺母面板状态读取普通螺丝时，类型卡片和专属参数布局没有同步切换的问题。
- 读取过程改为受保护的原子载入：暂停控件事件，载入组件数据，切换编辑上下文，再统一重建布局。
- 普通选择仍只改变顶部目标摘要；只有“读取组件”会改变面板模板。

## 咬合孔深度

- 面板只提供“完全贯穿”“螺杆长度 + 1D”和“螺杆长度 + 自定数值”。
- 自定数值采用追加毫米，孔底为 `嵌入深度 + 螺杆长度 + 追加深度`；允许兼容负值，但最终孔底必须有效。
- 新建螺丝和旧版跨会话预设默认使用 L+1D。
- 删除重复的宿主切割模块区域；顶部孔深、预览和导出布尔统一应用到全部同角色绑定。

## 迁移与兼容

- 组件 schema 升级为 v10。
- 旧 L+2D 自动迁移为等效的自定追加 `2D`；旧绝对盲孔迁移为保持原孔底位置的追加毫米。
- 智能宿主模板同步迁移，现有组件的宿主、绑定、组件 ID和实际切割结果保持不变。
- 插件 GUID、旧命令和 `RhinoMM.*` 元数据键继续兼容。
