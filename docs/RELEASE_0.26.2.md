# 参数化紧固件 0.26.2

## 修复

- 修复已经由 0.26.0–0.26.1 保存的“只咬合”组件在放入 Rhino、STEP 或 STL 中仍不切割宿主的问题。
- schema v13 会识别 v12 只咬合组件，并从智能咬合模板恢复唯一咬合绑定的预览和导出布尔状态。
- 面板即时修改咬合模块开关时，同时更新实际绑定和`SmartBindingProfile`，避免后续宿主复核重新出现状态分裂。

## 使用

- 旧组件无需删除或重新放置；重新打开文档后直接选择宿主导出即可。
- 用户主动关闭咬合孔“导出布尔”后，新版本仍会尊重该设置。

## 验证

- 增加 v12 错配组件迁移回归测试。
- schema v13 保留插件 GUID、组件 ID、绑定 ID和`RhinoMM.*`元数据键。
