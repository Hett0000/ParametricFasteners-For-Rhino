# 参数化紧固件 0.35.1 发布说明

## 框选后直接更新

- 修复单选或框选紧固件控制点后，修改面板参数会导致“更新”按钮不可用的问题。
- 面板在参数变化、选择变化、代理体转选、取消选择和更新完成后，都会重新读取 Rhino 当前控制点选择。
- 更新按钮 Tooltip 会显示即将应用模板的组件数量。
- 点击更新时仍会重新读取选择并执行完整事务预检，失败时不修改任何组件。

## 交互约定

- 场景选择只指定更新目标，不会改变面板模板。
- 只有“读取组件”会把已有组件参数载入面板。
- 损坏、缺失宿主或待重新绑定组件仍需先通过维护中心处理。

## 兼容性

- 插件版本：`0.35.1`
- 组件 schema：v17（未变化）
- 模板 schema：v2（未变化）
- 用户标准件库 schema：v1（未变化）
