# 参数化紧固件 0.40.4 / Parametric Fasteners 0.40.4

## 中文

0.40.4 移除主面板中的后台文档健康徽标。

- 主面板不再持续显示`需维护 N`或`需处理 N`。
- 后台健康扫描、组件导航器、维护中心和装配检查器保持不变。
- 用户主动执行更新、导出或检查时，真实错误仍会阻止操作并显示原因。
- “目标”行只显示当前选择摘要，不再因后台报告改变高度或内容。

组件 schema 保持 v21，模板 schema 保持 v5，模板库 schema 保持 v2。

## English

Version 0.40.4 removes persistent background document-health badges from the main panel.

- The main panel no longer shows `Maintenance required` or `Action required` counters.
- Background scanning, Fastener Navigator, Maintenance Center, and Assembly Inspector remain unchanged.
- Real errors found during explicit update, export, or inspection still block the operation and show the reason.
- The Target row now contains only the current selection summary.

Component schema remains v21, template schema remains v5, and template-library schema remains v2.
