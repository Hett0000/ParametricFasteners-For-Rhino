# 选择、读取与接管设计

## 1. 组件构成

RhinoMM 组件由三类对象共同表示：

1. **紧固件代理**：视口中可选择的简化螺丝/螺母几何，不含真实螺纹。
2. **组件参数**：序列化在 UserData 中的预设、规格、放置、打印配置和宿主绑定。
3. **按宿主切割体**：根据每个宿主的通孔或咬合角色分别生成的预览几何。

三者共享稳定的 `componentId`。代理是主要选择入口，切割体是次要入口；无论选择哪一种，插件都读取同一份参数。

## 2. 选择状态机

| 当前选择 | 面板状态 | 行为 |
| --- | --- | --- |
| 无对象 | 新建 | 使用最近一次预设，可开始放置 |
| 一个 RhinoMM 代理/切割体 | 编辑 | 读取组件参数，允许修改并应用 |
| 一个绑定宿主、仅关联一个组件 | 关联提示 | 显示该组件，可由用户进入编辑 |
| 一个绑定宿主、关联多个组件 | 选择组件 | 列出组件，不猜测目标 |
| 一个普通螺丝对象 | 接管 | 显示“接管为 RhinoMM 螺丝” |
| 多个 RhinoMM 组件 | 批量编辑 | 只开放共同且安全的字段 |
| 混合或不支持对象 | 只读提示 | 不修改选择，不进入错误模式 |

面板标题始终显示当前模式和组件短 ID，例如“正在编辑 · M6 · 4F2A”，防止用户误以为仍在新建。

## 3. 参数读取

读取顺序：

1. 从所选对象 UserData 读取 `componentId`。
2. 通过文档级反向索引找到代理、切割体和绑定宿主。
3. 校验 UserData 版本、代理 ID、预设版本和绑定完整性。
4. 索引不一致时扫描 RhinoMM 图层和 UserData 重建索引，再重试一次。
5. 将持久化数据复制到编辑草稿，面板不得直接绑定并修改 UserData 实例。

读取失败时保留对象选择并显示可修复诊断；不得把损坏组件当成普通模型再次接管。

## 4. 自动更新事务

修改类型、规格、补偿、角色或放置后：

1. 在内存草稿中计算全部最终尺寸。
2. 重建简化紧固件代理。
3. 为每个宿主重建专属切割体并验证相交。
4. 所有构建成功后才开始 Rhino Undo 记录。
5. 替换代理和切割体，写入新版 UserData，刷新双向索引。
6. 保持原 `componentId`、对象属性和有效绑定，恢复用户对代理的选择。
7. 通知停靠面板和视口重绘；导出服务自动读取新版参数。

任何步骤失败都不得留下“新代理＋旧切割体”之类的混合状态。写入前失败直接丢弃草稿；写入中失败回滚整个 Undo 记录。

## 5. 接管普通螺丝

### 支持输入

- 单个闭合 Brep。
- 单个 Extrusion。
- 单个 InstanceReference；只接管当前实例，不修改共享块定义。

首版不批量接管，不解析 Mesh/SubD，也不要求识别任意供应商的真实螺纹牙型。

### 候选分析

- 从圆柱面和旋转对称特征估算轴线。
- 从杆部候选估算公称直径。
- 从头部包围盒、圆柱/锥面和六边轮廓估算预设类型。
- 与数据表比较后输出候选规格、尺寸偏差和置信状态。
- 只有包含完整 RhinoMM UserData 的对象可以“精确读取”；几何分析结果始终是待确认候选。

### 确认与落盘

- 用户必须确认预设、规格、入口、轴向和宿主绑定。
- 接管前叠加显示原模型和新的简化代理，说明代理不保留真实螺纹、品牌标记或非标准细节。
- 默认把源对象隐藏并记录 `adoptedSourceObjectId`；插件代理在原位置创建。
- 可选“删除源对象”必须二次确认并支持 Undo；不得作为默认值。
- 如果接管对象本来是块实例，仅隐藏该实例，不编辑 InstanceDefinition。

## 6. 变换和删除

- 移动或旋转紧固件代理会更新组件放置坐标并重建所有切割体。
- 直接移动切割体不改变组件；插件应拦截或在命令结束后恢复参数生成的位置，并提示用户移动代理。
- 删除代理默认删除整个 RhinoMM 组件和切割体，但不删除接管源备份；Undo 可恢复。
- 删除单个切割体时，从参数自动重建，而不是把该绑定静默移除。
- 接管源对象被用户重新显示或删除时，不自动改变已接管组件，只更新源备份状态。

## 7. 测试矩阵

- 选择代理、任意切割体、唯一关联宿主和多关联宿主。
- 修改 M1.6、M6 的规格、补偿和两类宿主角色，检查所有预览自动更新。
- 重建中注入代理失败、单宿主切割失败和 UserData 写入失败，验证完整回滚。
- 接管标准外形 Brep、拉伸体、块实例、非标准头型和无法识别对象。
- 验证接管默认隐藏源对象、撤销恢复、重做再次接管，以及共享块定义不变。
- 保存并重开 3DM 后，从代理选择恢复组件索引与编辑状态。
