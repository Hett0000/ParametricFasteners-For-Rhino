| 项目 | 内容 |

## 1. 产品定义

RhinoMM 将常用紧固件安装空间抽象为带参数的“孔组件”。用户选择紧固件类型、规格和打印补偿后，可以在实体表面或指定起点快速放置切割体。孔组件在 3DM 中保持可编辑；只有通过插件导出 STEP/STL 时，才会在模型副本中执行布尔差集。

### 1.1 用户问题

- 常用螺钉沉孔和螺母槽需要反复查询尺寸并手工建模。
- FDM 孔径通常需要按打印机和材料增加或减少间隙。
- 直接布尔会破坏源模型，后续修改规格、位置或补偿成本高。
- 普通导出无法识别“尚未切割的孔组件”，容易漏切或把辅助几何导出。

### 1.2 产品目标

- 让常用孔型从选择规格到完成放置不超过一个连续流程。
- 让所有孔位可以重新选择规格、补偿、深度、方向和宿主。
- 导出结果可以直接进入切片或制造流程，同时确保源模型零改动。
- 所有尺寸来源、标准版本和补偿来源可追溯。

### 1.3 非目标

- 不生成真实内外螺纹。
- 不替代 Rhino 的通用实体修复和网格修复能力。
- 不在首版支持 Mesh、SubD、开放 Brep 或侧向插入式螺母通道。
- 不提供紧固件强度、壁厚或承载能力工程计算。

## 2. 首版用户故事

1. 作为 FDM 设计者，我能选择 M6 内六角圆柱头螺钉，在零件表面放置带沉孔的通孔。
2. 作为打印机使用者，我能保存“打印机＋材料”补偿配置，并对个别孔位覆盖补偿。
3. 作为 Rhino 用户，我能在曲面上选择一点，让孔轴沿局部法向放置，并在预览中翻转方向。
4. 作为机械设计者，我能把一个孔组件显式绑定到一个或多个实体，避免导出时误切邻近零件。
5. 作为装配设计者，我能让同一颗螺丝穿过第一个零件，并在第二个零件中形成较小的咬合预孔。
6. 作为模型维护者，我能在 Rhino 视口选择已有 RhinoMM 螺丝，让插件读取全部参数并进入编辑状态。
7. 作为设计者，我能修改已选螺丝的类型或规格，并让螺丝代理、通孔、咬合孔和导出结果自动同步更新。
8. 作为已有模型的使用者，我能选择普通螺丝实体或块，通过插件接管为可编辑的 RhinoMM 螺丝组件。
9. 作为打印准备人员，我能选择零件导出 STL/STEP；插件自动切孔，但不改变当前文档。

## 3. 功能需求

### 3.1 预设库

- `FR-PRESET-01`：提供内六角圆柱头、内六角沉头、六角头螺栓、1 型六角螺母四类预设。
- `FR-PRESET-02`：每类覆盖 M1.6、M2、M2.5、M3、M4、M5、M6、M8、M10、M12 中标准支持的规格。
- `FR-PRESET-03`：通孔提供紧配、普通、宽松三档，默认普通。
- `FR-PRESET-04`：每条数据记录内部 ID、显示名称、标准题录、等效 ISO 来源、版本和基础尺寸。
- `FR-PRESET-05`：数据文件版本不匹配、字段缺失或尺寸非法时禁止生成几何。

### 3.2 放置

- `FR-PLACE-01`：面放置支持封闭 Brep/Extrusion 的平面和曲面子面。
- `FR-PLACE-02`：用户在面上取点后，系统计算切平面和法向，并优先判断朝实体内部的方向。
- `FR-PLACE-03`：起点放置先选择一个或多个宿主，再选择起点和轴向第二点。
- `FR-PLACE-04`：放置过程实时显示切割体、轴线、入口位置和相交状态。
- `FR-PLACE-05`：提供翻转方向和六角槽绕轴旋转控制。
- `FR-LIFECYCLE-06`：宿主与组件整体旋转或镜像时，必须同步放置坐标系、控制点、隐藏切割体及宿主绑定；带复制选项的镜像必须生成独立组件与绑定 ID。
- `FR-LIFECYCLE-07`：镜像后的放置坐标系必须保持螺杆轴向与实际几何一致，不得因右手系重建而反转轴向。
- `FR-PLACE-06`：通孔按宿主轴向交点贯穿；咬合孔逐宿主支持贯穿、螺杆长度加一倍或两倍公称直径和自定义深度。

### 3.3 每宿主孔配合

- `FR-FIT-01`：一个孔组件可以绑定多个宿主，每个宿主独立保存轴孔角色。
- `FR-FIT-02`：轴孔角色至少包含“穿过通孔”和“螺纹咬合预孔”两类，同一宿主在同一组件中只能出现一次。
- `FR-FIT-03`：穿过通孔使用所选紧配/普通/宽松标准孔径，并叠加打印机孔径修正；最终孔径必须大于螺丝公称直径。
- `FR-FIT-04`：螺纹咬合预孔使用小于公称直径的圆柱孔，不生成真实螺纹；咬合缩量来自打印配置或该绑定的显式覆盖值。
- `FR-FIT-05`：咬合预孔最终直径必须大于零且小于螺丝公称直径，否则禁止放置和导出。
- `FR-FIT-06`：螺钉头沉孔/沉头只分配给一个“头部承座宿主”，默认是入口侧的穿过通孔宿主；咬合宿主默认只生成轴向预孔。
- `FR-FIT-07`：预览和绑定列表使用不同颜色区分两类切割，并逐宿主显示最终孔径、深度和有效性。
- `FR-FIT-08`：导出时必须针对每个宿主生成其专属切割体，禁止用一个统一圆柱同时切过所有绑定实体。
- `FR-FIT-09`：直接咬合量与材料、层高、打印方向和螺丝有关；没有已校准数据时必须要求用户输入，不提供未经标记的生产默认值。

### 3.4 打印补偿

- `FR-COMP-01`：打印配置保存名称、XY 尺寸增量和 Z 深度增量。
- `FR-COMP-02`：打印机 XY 修正直接加到建模孔径、沉孔直径或六角对边尺寸，仅增加一次，不按每侧重复计算。
- `FR-COMP-03`：Z 增量直接加到沉孔或螺母槽深度。
- `FR-COMP-04`：补偿允许正值和负值；最终尺寸必须大于零。
- `FR-COMP-05`：组件保存配置快照并允许单独覆盖，修改全局配置不得悄然改变既有组件。
- `FR-COMP-06`：内置“标准尺寸”配置，XY 和 Z 均为 0。

### 3.5 组件管理

- `FR-COMPONENT-01`：孔组件保存完整参数、放置坐标系和带孔配合角色的宿主绑定列表。
- `FR-COMPONENT-02`：一个参数化紧固件组件由可选择的简化紧固件代理、参数数据和按宿主生成的切割体组成；全部对象属于一个稳定命名的 Rhino Group，代理不生成真实螺纹。
- `FR-COMPONENT-03`：切割体显示在 `参数化紧固件::切割模块` 图层；紧固件代理显示在 `参数化紧固件::紧固件` 图层。
- `FR-COMPONENT-04`：选中紧固件代理或任一关联切割体后打开/聚焦插件，面板必须读取同一个组件的全部参数并切换到编辑模式。
- `FR-COMPONENT-05`：选中绑定宿主时，面板显示与其关联的 RhinoMM 组件列表，但不自动选择其中一个进行修改。
- `FR-COMPONENT-06`：修改类型、规格、补偿、绑定角色、深度、方向或放置坐标后，实时预览所有受影响几何；确认应用时在一个 Undo 记录内原子更新。
- `FR-COMPONENT-07`：自动更新必须保留 `componentId`、有效宿主绑定、图层、对象名称和用户选择；任何重建失败均回滚到修改前状态。
- `FR-COMPONENT-08`：支持重新绑定宿主。
- `FR-COMPONENT-09`：统一变换宿主时同步变换孔组件；不一致的多宿主变换将组件标记为失效。
- `FR-COMPONENT-10`：宿主被删除、替换或无法解析时，组件显示失效状态并阻止导出。
- `FR-COMPONENT-11`：创建、读取、编辑、接管、重新绑定和删除必须兼容 Rhino Undo/Redo。
- `FR-COMPONENT-12`：组件参数变更后，导出管线只能读取最新参数快照，不允许继续使用旧显示 Brep 或旧缓存。
- `FR-COMPONENT-13`：多选多个 RhinoMM 组件时只允许修改共同字段；可能破坏各自绑定的字段必须要求单独编辑。
- `FR-COMPONENT-14`：本体和切割模块分别保存 0–100% 不透明度；修改显示设置不得重建几何或创建重复材质。
- `FR-COMPONENT-15`：每个宿主分别保存预览开关和导出布尔开关；轴孔与头部切割体共用该宿主的设置。
- `FR-COMPONENT-16`：schema v1/v2 数据读取时迁移到 schema v3，默认本体 70%、切割模块 35%、全部模块可见并参与布尔。
- `FR-COMPONENT-17`：面板在 280 DIP 以上宽度和 Windows 100%–200% 缩放下不得出现横向滚动条；高频操作固定在底部。

### 3.6 普通模型接管

- `FR-ADOPT-01`：选择一个普通闭合 Brep、Extrusion 或块实例后，面板提供“接管为 RhinoMM 螺丝”。
- `FR-ADOPT-02`：若对象已包含有效 RhinoMM UserData，则直接读取编辑，禁止重复创建组件。
- `FR-ADOPT-03`：无插件数据时，系统可以从包围盒、圆柱轴和头部轮廓提出类型、规格和轴向候选，但候选必须显示置信状态并由用户确认。
- `FR-ADOPT-04`：几何分析无法可靠识别时，允许用户手动选择预设、规格、入口点和轴向，不得静默猜测。
- `FR-ADOPT-05`：确认接管前显示简化代理与原对象叠加预览，并明确提示插件代理不包含真实螺纹。
- `FR-ADOPT-06`：默认隐藏原对象并记录其 GUID，创建同位置的 RhinoMM 组件；提供显式“替换并删除源对象”选项，但不是默认行为。
- `FR-ADOPT-07`：块实例接管只处理当前实例，不修改可能被其他实例共享的块定义。
- `FR-ADOPT-08`：接管操作、源对象隐藏和恢复必须位于同一 Undo 记录中。
- `FR-ADOPT-09`：首版一次只接管一个普通对象；批量接管延后。

### 3.7 导出

- `FR-EXPORT-01`：用户选择一个或多个宿主，输出格式为 STEP 或 STL。
- `FR-EXPORT-02`：在临时无界面文档中复制宿主，根据每个绑定的孔配合角色分别生成切割体并执行布尔差集。
- `FR-EXPORT-03`：只对显式绑定且属于本次选择的宿主应用切割，不按空间相交扩展到其他实体。
- `FR-EXPORT-04`：切割组件不进入输出文件。
- `FR-EXPORT-05`：任一验证或布尔失败时取消整个导出，选中失败组件并报告原因。
- `FR-EXPORT-06`：先写临时文件，全部成功后再提交目标文件，避免留下半成品。
- `FR-EXPORT-07`：默认输出单位为毫米；STL 选择其他单位时提示该格式不记录单位元数据。
- `FR-EXPORT-08`：STL 默认为二进制，并提供网格精度设置；STEP 保留闭合实体。

## 4. 体验要求

- 主要界面为 Rhino 右侧 Eto 停靠面板，同时保留可脚本化命令。
- 预览必须在用户确认前明确显示方向、入口和切割范围。
- 错误信息必须指出宿主、孔组件、规格和失败阶段，不显示无上下文异常文本。
- 无文档单位、开放实体、非法补偿或失效绑定必须在布尔之前被发现。
- 高频用户可以在面板中连续放置同一规格，无需重复选择预设。
- 多宿主放置必须提供“宿主／角色／最终孔径／承座”列表，允许在确认前逐行修改。
- 面板必须明确区分“新建”“编辑所选组件”“接管普通对象”三种状态，避免误替换用户模型。
- 面板以 360 DIP 为断点在双列与单列参数布局间切换；长宿主名称换行或截断并通过提示显示全文。

## 5. 成功指标与验收

- 新用户能在不查尺寸表的情况下完成一个 M6 沉孔放置和 STL 导出。
- 重复放置相同规格时，每个孔位的操作不超过：选点、确认两次核心动作。
- 导出前后源对象 GUID、几何摘要和孔组件数量保持一致。
- 成功导出的 STEP 可重新读取为闭合实体；STL 可重新读取为有效闭合网格。
- M1.6、M2、M6、M12 四类孔型的关键尺寸与数据表及补偿公式一致。
- 同一 M6 组件绑定两个宿主时，可以在一次导出中得到较大的穿过通孔和较小的咬合预孔，且两个孔径分别符合各自公式。
- 选择 RhinoMM 代理后修改 M6 为 M5，组件 ID 和绑定保持不变，代理及所有关联孔径更新为 M5 结果；Undo 后完整恢复。
- 接管普通螺丝模型后，源对象默认被隐藏而非删除，撤销接管可恢复源对象并移除插件组件。
- 任何单个切割失败均不会覆盖已有目标文件。

## 6. 发布阶段

- **M0 文档与原型**：冻结产品范围、数据结构、界面方向和验收标准。
- **M1 几何核心**：完成预设读取、M1.6–M12、四类切割体、每宿主孔配合、补偿和几何测试。
- **M2 Rhino 交互**：完成面/点放置、UserData、编辑、绑定和 Undo/Redo。
- **M2.1 读取与接管**：完成选择同步、参数读取、自动重建和单对象接管。
- **M3 导出闭环**：完成无损 STEP/STL、错误诊断和单位处理。
- **M4 Beta**：使用实际打印件校准配置示例，完成 Yak 包和安装文档。

## 7. 主要风险

- Rhino 布尔结果受模型容差、实体质量和极小尺寸影响；必须先验证并提供具体诊断。
- 曲面入口的沉孔可能因局部曲率与壁厚产生意外相交；必须依赖实时预览和失败阻断。
- GB 采标尺寸表存在版权和版本风险；正式宣称符合国标前必须使用合法来源复核。
- 多宿主绑定在不同变换下会失去统一坐标关系；首版以标记失效和重新绑定处理。
- 咬合预孔不是标准内螺纹，实际保持力高度依赖材料和打印参数；产品必须要求校准并避免强度承诺。
- M1.6 对文档容差和 STL 网格精度敏感；容差或网格不足时应阻止导出而不是静默退化。
- 普通螺丝几何可能包含真实螺纹、倒角、非标准头型或变形，自动识别只能作为候选，不能直接宣称标准匹配。
# 0.9.0 增量需求

- 更新操作必须以当前选中的控制点集合为唯一目标，不得静默回退到历史编辑会话。
- 捕捉点模式必须支持一次定向后的连续放置，每个点创建独立的组件、绑定和控制点。
- Move 同步必须能够从事件对象解析文档，并在命令结束时收尾未收到 AfterTransform 的变换。
- Copy、Gumball Alt 复制、Paste 和 Import 必须为每个副本生成独立组件 ID和绑定 ID；复制宿主时优先重绑复制后的宿主。
- 无法唯一匹配宿主的副本必须保留控制点和代理体并标记为待重绑，禁止应用更新和布尔导出，直至通过“刷新 / 清理”完成重绑。
- 刷新必须以实际控制点位置为权威数据，仅重建不健康组件；健康组件不得产生无意义的对象 ID 或材质变化。
- 宿主重绑只允许使用用户当前选中的普通 Brep/Extrusion；匹配不唯一时保留组件并报告，不得删除。
- 缺少实际 Rhino Point 控制点是刷新删除组件的唯一条件。
# 0.10.0 增量需求

- 统计范围必须由用户明确选择“当前选择”或“全部组件”，不得在保存时静默改变。
- 统计对象必须具有实际 Rhino Point 控制点和可解析组件数据，并按组件 ID 去重。
- 螺丝按类型、规格和长度分组；六角螺母按类型和规格分组，长度留空。
- 面板统计预览和 Excel 必须使用同一个不可变统计快照。
- Excel 必须是真实 `.xlsx`，包含汇总和明细工作表，中文及特殊字符无需修复即可打开。
- Excel 写入失败时不得覆盖原目标或留下临时文件。

# 0.11.0 界面增量需求

- 主面板使用 Rhino 原生 Eto 控件建立克制的 macOS 风格视觉层级：浅灰画布、白色卡片、统一间距与单一蓝色主操作。
- 类型、规格和长度卡片按 340/420 DIP 断点响应式排列，最小 280 DIP 无横向滚动。
- 常用长度增加 35、40、45、50、60 mm；嵌入深度提供 `0` 和 `齐平` 快捷操作。
- 主面板不再显示独立 Excel 按钮，Excel 保存仅在统计窗口提供；兼容命令继续可用。

# 0.12.0 几何、批量模块与紧凑操作栏

- 代理几何合并必须验证完整头部和螺杆范围，失败时保留独立封闭 Brep，螺杆始终是稳定主代理。
- 批量更新按通孔与咬合孔角色统一全部用户可编辑的模块参数，同时保留各自宿主、绑定和头部承座关系。
- 主面板采用 28 DIP 紧凑控件；底部八项高频操作以单排纯图标呈现，并提供中文 Tooltip。
