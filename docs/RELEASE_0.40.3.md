# 参数化紧固件 0.40.3 / Parametric Fasteners 0.40.3

## 中文

0.40.3 删除主面板顶部重复的模板参数文字。

- 顶部“模板”行继续显示完整类型、规格、长度、装配方式和孔深摘要。
- 收藏按钮左侧不再重复显示规格和类型。
- 工具行固定为收藏、模板菜单、弹性空白和快速小窗开关。
- 收藏状态、模板载入、语言切换和快速小窗设置保持不变。

组件 schema 保持 v21，模板 schema 保持 v5，模板库 schema 保持 v2。

## English

Version 0.40.3 removes duplicated template parameter text from the main-panel header.

- The primary Template row remains the single summary for type, size, length, assembly mode, and depth.
- The favorite button no longer has a repeated type-and-size label to its left.
- The tool row is fixed as favorite, template menu, flexible space, and Quick Editor.
- Favorite state, template loading, language switching, and Quick Editor settings are unchanged.

Component schema remains v21, template schema remains v5, and template-library schema remains v2.
