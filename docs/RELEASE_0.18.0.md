# 参数化紧固件 0.18.0

## 新功能

- 热熔螺母新增独立“深度补偿”，最终切割深度为螺母长度加补偿值。
- 新建热熔螺母默认深度补偿为 1 mm，并通过 Rhino 插件设置跨会话保存。
- 面板明确区分“孔径补偿”和“深度补偿”，模块卡片显示本体长度、补偿量和最终切割深度。

## 切割行为

- 宿主仍须容纳热熔螺母本体。
- 仅补偿部分超过宿主时继续执行布尔，并自然形成贯穿孔。
- 达到宿主背面时切割体会增加实体外余量，避免共面导致布尔不稳定。
- Rhino、STEP、STL 和视口预览共用同一切割几何服务。

## 兼容性

- 组件 schema 升级为 v7。
- schema v6 及更早的热熔螺母保持 0 mm 深度补偿，原有模型几何不变。
- 插件 GUID、组件 ID、宿主绑定、`RhinoMM.*` 元数据键和旧命令保持兼容。
