# 参数化紧固件 0.24.1

## 改进

- 用户界面、统计、Excel 和文档统一使用“杯头”，完整名称使用“内六角杯头螺丝”。
- 单选螺丝摘要压缩为 `沉头 M3*30 +1切割 通1/咬1` 式一行格式；完整名称和孔深公式继续通过 Tooltip 显示。
- 完全贯穿、L+1D 和 L+自定值分别显示为“贯穿切割”“+1切割”和带符号的“+X/-X切割”。
- 底部八个操作图标在同一 Rhino 主题中统一颜色和按钮背景，不再因主操作状态切换白色图标或蓝色按钮。

## 兼容性

- 插件版本升级为 `0.24.1`，组件 schema 保持 v10。
- `FastenerKind.SocketCap`、插件 GUID、组件数据、旧模型和 RUI 工具列保持兼容。
