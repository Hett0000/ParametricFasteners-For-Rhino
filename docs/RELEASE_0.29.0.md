# 参数化紧固件 0.29.0

## 新功能

- 新增“螺纹咬合、只咬合、螺母固定”三项装配方式。
- 螺母固定模式为全部宿主生成正补偿通孔，并自动识别唯一末端螺母宿主。
- 支持普通或尼龙防松配套螺母、末端露出量和独立螺母槽补偿。
- 六角槽从螺母内侧端面向宿主背面贯穿，使用完整六角横截面覆盖范围处理倾斜和曲面背面。
- 智能预览、经典放置、批量更新、Rhino/STEP/STL 导出和复制变换均支持配套螺母。
- 物料统计按物理零件展开；Excel 明细增加装配方式、装配角色、末端露出量和螺母槽补偿。

## 兼容性

- 组件 schema 升级为 v16。
- v15 及更早的只咬合组件迁移为“只咬合”，其他旧螺丝迁移为“螺纹咬合”。
- 插件 GUID、组件 ID、旧命令和 `RhinoMM.*` 元数据键保持不变。
