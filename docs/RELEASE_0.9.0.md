# 参数化紧固件 0.9.0

## 本次更新

- 修复 Move 事件无法识别 Rhino 文档、AfterTransform 漏触发时组件不同步的问题；命令结束会自动完成待处理的组件坐标、对象 ID、宿主绑定和编辑缓存同步。
- “刷新 / 清理”升级为组件修复：以实际控制点位置重建移动后的紧固件；宿主 ID 丢失时可从当前选中的普通实体中按切割体重叠、轴线相交和轴向位置尝试唯一重绑。
- 无法唯一重绑的组件会保留并报告，不再被刷新误删；仅实际控制点不存在的组件会被级联清理。
- 捕捉点放置只需为第一点指定一次轴向，之后可连续捕捉多个点生成独立组件；Enter、右键或 Esc 结束本批，已生成组件保留。
- “应用更新”只处理当前选中的一个或多个控制点，不再回退到上一次读取的组件；批量更新继续保留每颗螺丝自己的位置、宿主、孔深和模块开关。

## 兼容性

- 插件版本：0.9.0。
- 持久化 schema：v5（未变化）。
- 插件 GUID、组件 ID、`RhinoMM.*` 元数据和旧命令保持兼容。

## Rhino 中建议验证

1. 选择宿主和组件一起 Move，检查螺杆、隐藏切割模块与控制点同步。
2. 模拟或遇到显示位置不同步时，选中移动后的宿主并点击“刷新 / 清理”。
3. 使用“捕捉点”放置，指定第一点和轴向后连续点击 3 个以上位置。
4. 面板仍显示 A 的参数时，选择 B 的控制点并点击“应用更新”，确认只修改 B。
