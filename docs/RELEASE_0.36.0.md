# 参数化紧固件 0.36.0：可靠内核与文档自愈

0.36.0 不增加紧固件类型，重点统一组件状态、几何准备、写入事务与文档健康检查。

## 核心变化

- 控制点元数据是组件参数的唯一持久化来源；代理体和切割体上的旧完整 JSON 不再参与普通读取。
- 控制点实际坐标与保存原点不一致时，以实际坐标生成有效快照，避免移动后组件回到旧位置。
- 新增不可变组件快照、参数签名、准备签名和派生几何签名。
- 智能预览、组件写入、Rhino、STEP 和 STL 输出共用统一几何准备服务。
- 批量更新在全部组件预检成功后才写入；异常时由内部变更日志恢复新增对象、旧对象、属性、组和材质。
- 编辑会话只缓存组件 ID、选择顺序和文档修订号；使用时重新从控制点生成快照。

## 文档健康

- 文档打开后在 Rhino Idle 阶段以短时间片执行只读扫描，不产生 Undo，也不把 3DM 标记为已修改。
- 状态分为：正常、需重建、待重绑和损坏。
- 正常文档不显示提示；存在问题时面板和导航器显示数量。
- “一键修复”只处理控制点、参数和宿主都明确的需重建组件。
- 待重绑组件仍须由用户在向导中确认宿主；损坏 JSON、重复控制点或组件 ID 冲突不会自动猜测恢复。
- 旧组件即使缺少派生签名，仍可依据控制点参数实时导出；显式修复后补齐新签名并清理派生对象旧 JSON。

## 兼容性

- 插件版本升级为 `0.36.0`。
- 组件 schema 保持 `v17`，模板 schema 保持 `v2`，用户库 schema 保持 `v1`。
- 插件 GUID、公开命令、组件 ID、绑定 ID及现有 3DM 数据保持兼容。
