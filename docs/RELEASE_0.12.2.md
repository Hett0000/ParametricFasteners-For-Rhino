# 参数化紧固件 0.12.2

## 响应式面板

- 面板断点改用扣除边距和滚动条预留后的实际可用宽度。
- 嵌入深度快捷按钮缩短，补偿模块改为分行显示，避免控件和说明文字撑出横向滚动条。
- 底部图标提升到 40 DIP、按钮高度提升到 58 DIP；宽面板保持八项单排，窄面板自动切换为四项两排。

## 补偿导出修复

- 模块预览及导出布尔开关同步更新当前组件和组件集合缓存，避免旧缓存回写。
- Rhino、STEP、STL 导出前自动提交当前编辑草稿，不再依赖控制点仍保持选中。
- 布尔服务以控制点数据为权威来源，并校验切割体的组件、绑定、宿主和持久化参数，拒绝使用过期切割体。

## 兼容性

- schema 继续使用 v5，插件 GUID、组件 ID、元数据键和旧命令保持兼容。
