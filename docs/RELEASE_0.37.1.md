# 参数化紧固件 0.37.1：快捷编辑精简与翻转/剖切功能移除

## 更新内容

- 快捷编辑窗口移除参数手柄、翻转、复制、检查和剖切按钮，仅保留读取、删除、应用和取消。
- 参数手柄及装配检查继续保留主面板、“更多…”和公开命令入口；复制继续使用 Rhino 标准命令。
- 智能摆放不再提供“翻转方向”，统一依据有效宿主面的朝内法线确定轴向；复杂方向可使用经典放置。
- 删除 `ParametricFastenersSectionView`、多选剖切入口和非文档型剖切显示管线。
- 组件 schema 保持 v19，模板 schema 保持 v4，现有组件参数与几何数据无需迁移。

## 验证重点

- 快捷编辑的参数预览、读取、删除、Enter应用和Esc取消。
- 智能摆放的自动朝内方向及经典放置轴向指定。
- 参数手柄旋转、Rhino复制与装配检查保留入口。
- 单点/批量更新、复制变换、文档自愈及Rhino/STEP/STL输出回归。
