# 参数化紧固件 0.5.0 实现说明

## 放置

- 放置提示可直接选择宿主面，也可选择“捕捉点”进入 Rhino 标准对象捕捉。
- 捕捉点支持端点、中点、圆心、交点、节点和普通点，随后由第二点指定轴向。
- 捕捉点位于已选封闭宿主表面时，最近宿主作为头部宿主，轴向自动校正为朝向实体内部。

## 控制点生命周期

- 控制点是读取和编辑参数化紧固件的唯一选择入口。
- 用户删除控制点时，同一组件的代理体、轴孔切割体、头部切割体和几何组随之删除，宿主保持不变。
- 级联删除属于当前 Rhino Delete/Undo；组件内部更新通过抑制作用域避免误触发级联删除。

## 批量更新

- 框选多个控制点后读取，面板进入批量模式并以第一个控制点为参数模板。
- 类型、规格、长度、头部嵌入、孔径修正、通孔配合和咬合缩减统一应用。
- 各组件保留自己的组件 ID、放置坐标、宿主、孔深、预览和导出布尔开关。
- 透明度调整即时同步到全部已读取组件。
- 全部组件先完成预检，再在一个 Undo 记录中提交；任何预检失败时不修改文档。

持久化 schema 继续使用 v4，插件 GUID、旧命令和 `RhinoMM.*` 元数据键保持兼容。
