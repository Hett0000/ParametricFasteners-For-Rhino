# 参数化紧固件 0.30.1

## 快速编辑器

- 视口快速编辑器压缩为约 252 DIP 宽，并根据螺丝、六角螺母或热熔螺母自动调整高度。
- 标题只显示 `M3X20`、`M3X5` 或 `M5` 等核心规格，完整组件信息保留在悬停提示中。
- 移除小窗中的读取、手柄、翻转和删除按钮，仅保留“确定”和“取消”。这些功能仍可从主面板、更多菜单或独立命令使用。
- Enter 等同于确定，Esc 等同于取消；确定或取消后，同一控制点保持选中时不会立即重新弹出小窗。
- 有效预览不再占用状态行；只有警告或错误才显示一行紧凑提示。

## 主面板

- 模板栏增加“快速小窗”开关，默认开启并跨 Rhino 会话保存。
- 关闭开关会立即隐藏当前快速编辑器；重新开启后对当前单选控制点恢复延迟显示。
- 删除“更多…”菜单中的重复自动快速编辑器选项。

组件 schema 继续使用 v16，现有模型、模板、几何、绑定及导出行为无需迁移。
