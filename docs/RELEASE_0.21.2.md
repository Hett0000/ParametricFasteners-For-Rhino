# 参数化紧固件 0.21.2

## 深嵌螺丝头通道

- 修复螺丝头嵌入深度超过头高时，物体表面到螺丝头顶部之间残留实体的问题。
- 杯头和六角头切割体现在连续覆盖放置面外侧至螺丝头底部。
- 深嵌沉头螺丝使用“圆柱入口段 + 正确角度截锥”，入口段与截锥保留少量内部重叠以提高布尔稳定性。
- 同一宿主绑定可保存并显示多个头部切割 Brep；预览、组件更新和 Rhino/STEP/STL 导出共用相同几何。

## 兼容性

- 插件版本升级为 0.21.2，组件 schema 保持 v8。
- 不改变螺杆孔深、宿主识别、嵌入深度定义、组件 ID或现有绑定。
- 0.21.1 的 Rhino 深色工具栏 SVG 图标适配继续包含在本版本中。
