# 参数化紧固件 0.17.1

## 全局显示

- “全局显示”中的本体和切割模块透明度作用于当前文档全部有效组件。
- 读取、单选或框选组件不会再改变透明度滑块。
- 设置跨 Rhino 会话保存，并作为新建螺丝、六角螺母和热熔螺母的默认值。
- 文档同步只更新组件元数据和稳定材质，不重建几何或产生重复材质，并使用一次 Undo。

## Rhino 导出操作

- 左击面板“放入 Rhino”图标：只生成布尔后的普通宿主。
- 右击同一图标：生成布尔宿主及关联紧固件渲染实体。
- 新增脚本化命令 `ParametricFastenersExportToRhinoWithFasteners`。
- 移除 0.17.0 的“包含紧固件实体”复选框；旧设置键不再读取。

## 兼容性

- RUI 工具列和旧 Rhino 导出命令继续执行普通宿主导出。
- STEP、STL、统计、组件 GUID、`RhinoMM.*` 元数据和 schema v6 保持不变。
