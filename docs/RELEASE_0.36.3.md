# 参数化紧固件 0.36.3：双模式咬合孔入口倒角

## 新功能

- “螺纹咬合”的入口倒角新增“轴向45°”与“表面等距”切换，两种方式共用 `C0.05–C5.00 mm`。
- 轴向45°保持0.36.2的平面解析和曲面求解结果，继续作为新建默认方式。
- 表面等距使用实际布尔孔口边环，使宿主表面和孔壁各退让相同C；倾斜螺丝不再被轴向45°的临界角限制。

## 安全边界

- 表面等距仅支持单一连续平面入口；曲面、跨非共面入口、边缘材料不足或多个候选孔口会停止操作并建议改用轴向45°。
- 主孔孔底、完全贯穿、L+1D和L+自定深度均不因倒角方式改变。
- 预览、文档切割对象、一键修复及Rhino、STEP、STL输出使用同一宿主专属切割体；无法稳定复现时零写入。

## 数据与兼容

- 插件版本：`0.36.3`
- 组件 schema：`v19`
- 模板 schema：`v4`
- v18倒角组件自动迁移为轴向45°，既有几何语义保持不变。
- 插件GUID、组件ID、绑定ID和公开命令保持不变。
