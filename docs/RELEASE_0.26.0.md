# 参数化紧固件 0.26.0

## 精简界面

- 主面板删除“使用说明”和内嵌“全局显示”，减少首屏高度与滚动。
- “更多…”菜单新增“全局显示…”，通过独立主题窗口调整本体和切割模块透明度。
- 滑块实时预览当前文档全部组件；确定后一次提交并保存，取消恢复原状态。

## 只咬合加强筋模式

- 螺丝新增“只咬合”开关，默认关闭。
- 开启后只绑定放置面宿主，不创建穿过体；头部承座仍由该宿主承担。
- 宿主必须完整容纳螺杆，插件会根据实际轴向厚度给出最大允许长度。
- 螺杆范围内出现第二实体时停止生成，避免无意穿入其他零件。
- 完全贯穿、L+1D和L+自定值三种咬合孔深继续可用。

## 兼容性

- 组件 schema 升级为 v12；旧组件迁移后保持关闭“只咬合”，原绑定不变。
- 智能预览、经典放置、批量更新、复制生命周期及 Rhino/STEP/STL 导出使用相同校验规则。
