# 参数化紧固件 0.22.0

## 六角螺母嵌入深度

- 六角螺母新增 `0`、`全埋` 和非负自定义嵌入深度。
- `0 mm` 时螺母完全外露，不创建视口切割体，也不修改 Rhino、STEP 或 STL 导出宿主。
- `全埋` 使用当前规格的标准螺母厚度；自定义深埋会从宿主表面生成连续六角通道。
- 修改规格时，原先处于全埋状态的组件会跟随新规格厚度；自定义毫米值保持不变。
- 宿主厚度小于实际嵌入深度时，放置或更新会停止且不写入部分结果。

## 兼容性

- 组件 schema 升级为 v9。
- v8 及更早版本的六角螺母自动迁移为标准全埋深度，保持原有位置与切割结果。
- 插件 GUID、组件 ID、旧命令和 `RhinoMM.*` 元数据键保持兼容。
