# 参数化紧固件 0.39 界面规范

## 设计方向

界面采用 Rhino 原生精密风格：系统字体、平直边界、低对比层级和克制的状态色。禁止圆角重绘、渐变、阴影、持续动画和非系统字体。

## 尺寸与间距

| 角色 | 规范 |
| --- | --- |
| 页面摘要 | 11 DIP，加粗 |
| 分组标题 | 10 DIP，加粗 |
| 字段与输入 | 9 DIP |
| 辅助信息 | 9 DIP，次级色 |
| 表单控件高度 | 26 DIP |
| 快捷窗字段高度 | 22 DIP |
| 底部操作高度 | 36 DIP |
| 间距 | 3 / 4 / 6 / 8 / 12 DIP |
| 卡片边界 | 1 DIP弱边框 |

## 主面板信息架构

1. 模板摘要：说明即将用于创建或更新的参数。
2. 目标摘要：只反映Rhino当前选择，不修改模板。
3. 模板工具：模板名称、收藏、模板菜单、快速小窗开关。
4. 参数内容：基础尺寸、装配方式、孔与切割。
5. 操作状态：只显示短期成功、警告或错误。
6. 操作栏：八项固定操作，按编辑、输出、检查弱分组。

类型、规格、常用长度分别固定为5、5、6列。280–319 DIP时尺寸字段分行；320–419 DIP采用紧凑双列；420 DIP及以上允许三字段并排。任何宽度都只允许纵向滚动。

## 快捷编辑窗

- 宽度约268 DIP，不提供折叠状态或内部滚动条。
- 标题显示紧固件类型和核心规格；第二行显示装配方式与宿主数；第三行显示健康状态。
- 错误区始终为单行，完整内容进入Tooltip与命令行。
- 操作顺序固定为读取、取消、应用、删除。
- 应用使用Rhino蓝；删除默认使用浅危险色，二次确认使用高对比深红。
- 位置从右下、左下、右上、左上依次评估，选择不越界且与组件屏幕范围重叠最少的位置。

## 操作颜色

- 选中卡片与确认：Rhino蓝。
- 普通操作图标：同一主题内统一颜色，不因主操作改变。
- 成功、警告、错误、危险：仅用于对应语义，不作为装饰。
- 禁用状态继续使用Rhino原生透明度和禁用文字色。
