# 参数化紧固件 0.11.0

## 界面

- 主面板采用浅灰画布、白色内容卡片、8/12/16 DIP 间距和单一蓝色主操作。
- 紧固件类型、规格与常用长度按 340/420 DIP 断点响应式换行，280 DIP 下仅垂直滚动。
- 常用长度扩展为 8、10、12、15、20、25、30、35、40、45、50、60 mm。
- 嵌入深度增加 `0` 与 `齐平` 快捷按钮；螺母模式下整组控件禁用。
- 底部操作区精简为固定 4×2，仅新建或编辑的当前主操作使用蓝色强调。

## 统计与 Excel

- 主面板和 Rhino 工具列移除独立“导出 Excel”入口。
- Excel 保存统一收纳到“紧固件统计”窗口。
- 统计范围使用等宽切换卡片；数量摘要在宽窗口显示 4 列，窄窗口显示 2×2。
- `ParametricFastenersExportExcel` 兼容命令继续保留，调用后聚焦“保存 Excel”。

## 兼容性

- 持久化 schema 保持 v5。
- 插件 GUID、组件 ID、`RhinoMM.*` 元数据键和旧命令保持兼容。
