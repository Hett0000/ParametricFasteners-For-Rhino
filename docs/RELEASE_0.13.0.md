# 参数化紧固件 0.13.0

## 界面

- 新增集中式 `ResponsiveLayoutProfile`，在常用面板宽度下固定使用 4 列类型、5 列规格和 6 列长度；窄于 340 DIP 时长度切换为 4 列。
- 卡片选择器按每一行实际项目重新均分宽度，不再由文本首选宽度决定列宽，也不再插入不可见占位项。
- 自定义长度与嵌入深度在标准宽度并排，三个孔参数同排显示；顶部摘要和状态各限制为一行，并保留完整 Tooltip。
- 底部八项操作改为 40 DIP 高的固定单排工具栏，在组件操作与输出操作之间增加弱分组间隔。

## 图标

- 废弃运行时手绘和放大图标，改用统一的 24×24 Lucide 线性语义图标。
- 面板内嵌 24、36、48 px 普通及反白资源，RUI 内嵌 16、24、32 px 资源，运行时不缩放位图。
- 普通状态统一使用深蓝灰，主操作使用 Rhino 蓝底与白色图标。
- 图标来源及 ISC 许可见根目录 `THIRD_PARTY_NOTICES.md`。

## 兼容性

- 插件版本升级为 0.13.0，持久化 schema 保持 v5。
- 组件 GUID、命令、导出、统计和旧模型数据保持兼容。
