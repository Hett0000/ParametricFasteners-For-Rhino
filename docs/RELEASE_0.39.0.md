# 参数化紧固件 0.39.0

0.39.0 是 1.0 之前的界面候选版本。本次不修改紧固件几何、宿主绑定、组件 schema 或导出结果，重点完成主面板与快捷编辑窗的视觉和操作收口。

## 主面板

- 顶部固定区分别显示当前模板、选择目标和模板工具，临时成功、警告与错误使用独立状态条。
- 参数区合并为一个连续内容表面，以弱分隔线组织“基础尺寸、装配方式、孔与切割”。
- 类型、规格和常用长度固定使用 `5 / 5 / 6` 列网格；280 DIP 宽度下仍完整显示且不产生横向滚动条。
- 表单控件统一为 26 DIP，底部八个图标统一为36 DIP，采用3/4/6/8/12 DIP间距系统。
- 关闭倒角或架桥时，相关数值保持原位置但进入禁用状态，避免参数区上下跳动。
- 预览和布尔开关改为按角色排列的紧凑行，减少重复标题。

## 快捷编辑窗

- 固定约268 DIP宽且始终展开，标题、装配摘要、健康状态和错误信息相互独立。
- 底部固定为 `读取｜取消｜应用｜删除` 单排等宽按钮。
- 错误信息只占一行；完整原因保留在 Tooltip 和 Rhino 命令行，不会再挤压操作按钮。
- 采用四象限候选定位，优先避开控制点和组件几何，并始终限制在活动视口内。
- 应用期间静态显示“处理中”，阻止重复事务；删除继续使用两阶段危险确认。

## 操作一致性

- 增加统一的操作 ID、描述和协调器，集中保存八项操作的名称、图标、分组、Tooltip及左右键命令。
- 底部操作栏保持“放置、更新、维护、Rhino、STEP、统计、检查、更多”的原顺序。
- 放置和Rhino导出的左右键语义保持不变；主面板更新仍在点击时读取Rhino当前真实选择。

## 兼容性

- 插件版本：`0.39.0`
- 组件 schema：`v21`
- 模板 schema：`v5`
- 模板库 schema：`v2`
- 插件 GUID、公开命令、已有3DM组件、参数和导出规则均不变。
