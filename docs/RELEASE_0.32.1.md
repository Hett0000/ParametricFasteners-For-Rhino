# 参数化紧固件 0.32.1 热修复

修复 0.32.0 中智能放置始终显示“无法放置 · 未命中封闭实体”的严重回归。

## 原因

文档级空间索引在返回候选宿主时，通过缓存 `RhinoObject.Document` 反查当前对象。Rhino 在部分命令和文档事件阶段会暂时分离该对象包装，导致正常的封闭 Brep/Extrusion 被错误排除。

## 修复

- 始终使用当前 `RhinoDoc.Objects.FindId`确认对象是否仍存在、可见且未锁定。
- RTree 查询零结果时，复核索引中的宿主包围盒。
- 若索引仍未观察到候选，回退到 0.30 已验证的直接宿主捕获流程。
- 回退仅在零结果时执行，不影响正常空间索引性能。

组件 schema 保持 v16，已有模型无需迁移。
