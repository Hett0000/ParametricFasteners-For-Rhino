# 参数化紧固件 0.23.0

## 模板式批量更新

- 面板参数改为独立更新模板。选择控制点只指定目标，不再自动载入或覆盖当前参数。
- 顶部第一行显示模板摘要，第二行显示当前选择的规格分布、宿主数量和健康状态。
- 点击“读取组件”才载入已有组件；多选时以选择顺序中的第一颗作为模板，同时保留整批更新目标。
- 类型、规格、长度、嵌入深度、孔径修正、通孔配合、咬合缩减和咬合孔深度可一次应用到全部选中组件。
- 更新完成后保持面板模板，并重新选中重建后的控制点，便于连续处理多批对象。

## 孔深与模块

- 咬合孔深度提升为始终可见的主参数，支持贯穿、L+1D、L+2D 和自定义深度。
- 智能组件保存的新宿主模板同步采用当前孔深；经典组件继续保持原宿主集合。
- 未明确修改预览或导出布尔开关时，各组件原值保持不变；明确修改后才批量覆盖。
- 单组件显式读取后，宿主模块仍可保留独立孔深覆盖。

## 可靠性与兼容性

- 选择监听和编辑会话拆分，复制、移动、放置或刷新时的内部同步不再覆盖面板模板。
- 批量更新先完成全部预检，再使用一次 Undo 原子提交；失败时整批零写入。
- 新增更新模板核心测试，覆盖孔深统一、开关保留/覆盖、智能宿主模板和单宿主局部覆盖。
- 插件版本升级为 0.23.0，组件 schema 保持 v9；现有组件、GUID、命令和 `RhinoMM.*` 元数据保持兼容。
