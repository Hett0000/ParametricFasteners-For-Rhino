# 参数化紧固件 0.12.0

## 几何修复

- 沉头和六角头螺丝的头部与螺杆增加内部重叠，避免共面布尔只返回螺丝头。
- 合并结果必须覆盖完整头部和螺杆轴向范围；异常时自动回退为独立封闭 Brep。
- 分离显示时螺杆使用稳定的 `RhinoMM.ProxyPart=Shaft` 标记，并优先作为 `ProxyObjectId`。

## 批量补偿模块

- 批量模式按通孔和咬合孔分别显示同步模板。
- 通孔统一配合、预览和导出布尔；咬合孔统一缩减、深度、自定义深度、预览和导出布尔。
- 宿主、绑定、头部承座和目标专属附加修正继续保留；全部组件预检通过后才在一次 Undo 中提交。

## 紧凑面板

- 控件高度压缩为 28 DIP，卡片和字段使用 4/8/12 DIP 间距。
- 宽面板并排显示自定义长度、嵌入深度及三个孔参数。
- 底部改为读取、放置、更新、刷新、放入 Rhino、STEP、统计和更多八个纯图标按钮。
- 图标提供 1x、1.5x、2x 帧和完整中文 Tooltip；280 DIP 下保持单排且不产生横向滚动。

## 兼容性

- 持久化 schema 保持 v5。
- 插件 GUID、组件 ID、宿主绑定、旧命令及 `RhinoMM.*` 元数据保持兼容。
