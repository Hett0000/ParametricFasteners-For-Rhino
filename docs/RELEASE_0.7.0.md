# 参数化紧固件 0.7.0

## 主要更新

- 面板参数拆分为“紧固件尺寸”和“孔设置”，规格与长度卡片采用稳定等宽布局。
- 强化卡片选中态、编辑状态提示和底部主操作层级。
- “导出”菜单提供放入 Rhino、STL 和 STEP 三种入口。
- 新增 `ParametricFastenersExportToRhino`：在临时副本上完成布尔后，以联合包围盒底面中心跟随鼠标并单击放置。
- Rhino 内成果为普通 Brep，继承宿主图层和显示属性，清除 `RhinoMM.*` 元数据并统一成组。
- STL/STEP 和 Rhino 内导出共用同一布尔服务，文件导出改用标准保存对话框。

## 兼容性

持久化 schema 保持 v5。插件 GUID、组件 ID、宿主绑定、旧 `RhinoMM.*` 元数据键和现有导出命令保持兼容。
