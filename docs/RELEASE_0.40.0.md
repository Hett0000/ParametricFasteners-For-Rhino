# 参数化紧固件 0.40.0 / Parametric Fasteners 0.40.0

## 中文摘要

0.40.0 增加完整的简体中文与英文界面切换。“更多 → 设置 → 语言”可选择自动、简体中文或 English，并跨会话保存。主面板、快捷窗、二级窗口、命令提示、诊断、统计、Excel/CSV及交付名称使用统一资源。

语言切换立即刷新插件窗口并保留草稿、选择和任务状态；正在运行的 Rhino 命令从下次运行起采用新语言。公共命令、组件数据、元数据键和 3DM 内部结构名称保持稳定。侧边栏标题在重启 Rhino 后更新。

## English summary

Version 0.40.0 adds a complete Simplified Chinese and English interface. Choose Auto, Simplified Chinese, or English from **More → Settings → Language**. The setting persists across Rhino sessions and covers panels, compact editing, secondary tools, command prompts, diagnostics, statistics, Excel/CSV output, and generated delivery names.

Open plug-in views refresh immediately without losing drafts, selections, or task state. A Rhino command already in progress keeps its startup language. Public command names, component data, metadata keys, and stable 3DM structure names do not change. The sidebar caption follows the selected language after Rhino restarts.

## Compatibility

- Plug-in version: `0.40.0`
- Component schema: v21
- Template schema: v5
- Template library schema: v2
- No geometry or existing-document migration
