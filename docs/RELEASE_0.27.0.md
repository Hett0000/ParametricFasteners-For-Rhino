# 参数化紧固件 0.27.0

## 主要改进

- 修复倾斜、楔形和曲面宿主背面可能残留薄层的问题。通孔及完全贯穿咬合孔现在覆盖整个最终孔径圆柱与宿主的轴向范围。
- 取消通孔配合选择。新公式为：
  - 通孔：`D + 孔径修正 + 目标附加修正`
  - 咬合孔：`D − 咬合缩减 + 目标附加修正`
- 面板显示通孔与咬合孔的即时计算直径；Excel 明细同步输出两类最终直径。
- 正常智能摆放必须完整穿过第一宿主并进入后方咬合宿主，避免把未穿透的单一实体误识别为普通装配。
- schema 升级到 v14。旧组件不自动改变孔径；只有用户明确点击“更新”后才切换新公式。

## 兼容性

- 插件 GUID、组件 ID、绑定 ID、旧命令和 `RhinoMM.*` 元数据键不变。
- “全部通孔”“全部咬合”、经典放置和“只咬合”继续遵循原有识别规则。
- 盲孔、L+1D 和 L+自定深度仍严格止于计算孔底。
