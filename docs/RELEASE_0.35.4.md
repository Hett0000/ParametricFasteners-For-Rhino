# 参数化紧固件 0.35.4

## 螺丝头离面间隙

- 杯头、沉头和六角头螺丝的“嵌入深度”扩展为“嵌入/离面”：正值嵌入、零值贴面、负值离面。
- 负值移动整颗螺丝，但控制点仍固定在原放置面；摘要以“离面 X mm”显示，避免把负数误解为嵌入。
- 螺杆末端、智能宿主识别、咬合孔深、只咬合长度上限和螺母固定位置统一使用`嵌入/离面 + 螺杆长度`。
- 偏移小于等于零时不生成头部沉孔、沉头承座或通道；杯头悬垂架桥自动关闭。
- 离面距离达到或超过螺杆长度时阻止放置或更新；六角螺母仍只允许非负嵌入。

## 编辑与兼容

- 主面板字段改为“嵌入/离面 mm”，快速编辑小窗使用“偏移”，参数手柄支持向放置面外侧拖动。
- 模板、最近使用、收藏、重复更新和批量更新均可保存螺丝负偏移。
- 组件 schema 保持 v17，旧模型无需迁移，插件版本升级为`0.35.4`。
