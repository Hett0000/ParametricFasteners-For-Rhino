# 参数化紧固件 0.38.5

## 重点更新

- 导出改为严格的宿主范围隔离：只准备所选宿主的直接绑定，文档中其他损坏或待重绑组件只形成提示。
- 热熔螺母本体或深度补偿超过宿主厚度时继续按完整入口截面切透，贯穿属于警告而非错误。
- 装配检查器支持问题多选、同步选中控制点、联合定位和事务式批量删除；宿主不会被删除。
- 轴向宿主区间采用精确 Brep 求交、实体内外判断、交点聚类和接缝微偏移多数判定。
- 自动识别咬合体失败时可以点击后方封闭实体确认；确认宿主写入组件并在后续长度更新中保持固定。
- 维护中心提供“解除咬合确认”，用于恢复自动识别。

## 数据与兼容

- 插件版本：`0.38.5`
- 组件 schema：`v21`
- 模板 schema：`v5`
- 模板库 schema：`v2`
- v20 及更早组件迁移时确认宿主为空，继续使用自动识别。

## 安装

推荐使用 Release 中的 Yak 或离线安装包。安装完成后完全退出并重新启动 Rhino 一次。
