# 参数化紧固件 0.20.2

本版本修复智能摆放期间修改长度、规格或切割预设后，虚拟紧固件、切割体和最终导出结果不一致的问题，并优化视口提示。

## 修复内容

- 智能摆放每次计算使用同一份不可变参数快照，不再缓存命令启动时的规格和切割预设。
- 面板参数改变后立即刷新虚拟紧固件、本体长度、切割深度和方向箭头。
- 点击放置前强制按最新参数重新计算，保存后校验组件几何参数一致性。
- 连续摆放时，参数修改只影响后续组件，不改变已经放置的组件。
- 提示文字移动到当前视口底部上方，以紧凑 HUD 显示，不再遮挡鼠标准心和螺丝头。

组件 schema 保持 v7，既有模型、统计和导出格式不变。
