# 参数化紧固件 0.30.3｜3–5 分钟视频教程文案

## 视频定位

- **目标受众**：使用 Rhino 进行产品、结构与 3D 打印设计的专业设计师。
- **目标时长**：约 4 分钟。
- **核心案例**：两块板材通过一颗 M3 内六角杯头螺丝连接；前板为穿过通孔，后板为螺纹咬合孔。
- **核心信息**：快速放置、参数化修改、批量更新、非破坏导出。
- **录制版本**：参数化紧固件 `0.30.3`，Rhino 8 Windows。

---

## 分镜脚本

### 0:00–0:15｜成果引入

**画面操作**

1. 先展示两块尚未开孔的板材。
2. 快切到已经完成通孔、杯头沉孔和咬合孔的布尔成果。
3. 打开剖切视图或将前板短暂隐藏，展示前后两种不同孔径。
4. 最后回到参数化组件状态，显示螺丝、控制点和半透明切割预览。

**旁白**

> 在 Rhino 里制作 3D 打印螺丝孔，通常需要重复建模、计算补偿，再执行多次布尔。参数化紧固件把螺丝、孔径、孔深和宿主关系保存为可编辑组件，修改参数后可以统一更新，最终导出时再完成布尔切割。

**屏幕字幕**

`参数化紧固件 · 非破坏式紧固件与孔设计`

**鼠标与剪辑提示**

- 开场使用 1 秒左右的“原始模型／布尔成果”左右对比。
- 剖切画面用蓝色标注前板通孔、橙色标注后板咬合孔。
- 不展示复杂命令行过程，先让观众看到最终价值。

---

### 0:15–0:30｜打开插件

**画面操作**

1. 在 Rhino 命令行输入 `ParametricFasteners`。
2. 展示右侧“参数化紧固件”停靠面板及侧边栏图标。
3. 鼠标从左到右掠过底部八个操作图标，停留在“放置/绑定”上显示 Tooltip。

**旁白**

> 安装插件后，输入 ParametricFasteners 打开右侧面板。底部工具依次用于读取、放置、更新、刷新、放入 Rhino、导出 STEP、统计和更多操作。这里我们直接从一组两板连接开始。

**屏幕字幕**

`命令：ParametricFasteners`

**鼠标与剪辑提示**

- 命令文字放大 120%，停留约 1 秒。
- 面板侧边栏图标做一次轻微高亮，不展开安装流程。

---

### 0:30–1:30｜设置参数并智能放置

**画面操作**

1. 类型选择“杯头”，规格选择 `M3`，常用长度选择 `20`。
2. 嵌入深度点击“齐平”，让杯头顶面与前板表面齐平。
3. 装配方式选择“螺纹咬合”。
4. 设置孔径修正 `0.20 mm`、咬合缩减 `0.35 mm`。
5. 咬合孔深度选择“螺杆长度 + 1D”。
6. 点击底部“放置/绑定”图标。
7. 将鼠标移动到前板表面，展示虚拟杯头螺丝、切割体以及宿主轮廓。
8. 在有效预览位置单击，生成组件；按 Esc 结束连续放置。

**旁白**

> 选择杯头、M3 和 20 毫米长度。嵌入深度设为齐平，装配方式使用螺纹咬合。通孔孔径以公称直径加孔径修正计算，这里得到 3.2 毫米；咬合孔以公称直径减咬合缩减计算，得到 2.65 毫米。咬合深度选择螺杆长度加 1D。
>
> 点击放置后，虚拟螺丝会跟随鼠标。插件沿螺杆方向识别宿主：前板显示为穿过体，后板显示为咬合体，同时预览杯头沉孔和两种轴孔。确认位置后单击即可生成，按 Esc 结束连续放置。

**屏幕字幕**

依次显示：

- `通孔 = D + 孔径修正 = Ø3.20`
- `咬合孔 = D − 咬合缩减 = Ø2.65`
- `蓝色：穿过体 · 橙色：咬合体`

**鼠标与剪辑提示**

- 参数输入区域使用局部放大，输入完一项立即恢复正常比例。
- 智能预览至少保留 4 秒，让观众看清螺丝本体、沉孔和宿主颜色。
- 单击生成时增加圆形鼠标点击动画。
- 如果模型遮挡明显，可在生成后快速切换一次半透明或剖切显示。

---

### 1:30–2:10｜快速修改已有螺丝

**画面操作**

1. 单击位于安装面上的控制点。
2. 等待约 250 毫秒，展示标题为“杯头 M3X20”的快速编辑小窗。
3. 将长度从 `20` 修改为 `25`。
4. 展示半透明预览中螺杆和切割范围同步改变。
5. 点击“确定”，或在画面中同时提示可按 Enter。
6. 再次展示控制点仍位于原安装面。

**旁白**

> 已经生成的组件通过安装面上的控制点管理。单选控制点后，会出现紧凑的快速编辑窗口。把长度从 20 改为 25，视口会先显示新的几何预览。点击确定，螺丝本体、宿主识别和切割体会在一次更新中同步重建，而控制点始终保留在原来的安装面上。

**屏幕字幕**

`杯头 M3X20 → 杯头 M3X25`

**鼠标与剪辑提示**

- 控制点加 150% 局部放大和短暂描边。
- 快速小窗不要遮住螺丝，录制前将视口留出右下方空间。
- 点击“确定”后用一次短剖切确认孔深已经同步变化。

---

### 2:10–2:50｜模板式批量更新

**画面操作**

1. 在主面板把模板改为 `M4`、长度 `25`，其他参数保持当前设置。
2. 在视口框选 3 个螺丝控制点。
3. 展示顶部模板摘要和“已选 3 个”的选择摘要。
4. 指出面板参数没有因选择而变化。
5. 点击底部“应用更新”图标。
6. 展示三颗螺丝和对应切割预览同时更新。

**旁白**

> 批量修改时，先把面板设置成需要应用的模板，再框选多个控制点。场景选择只指定更新目标，不会覆盖面板里的参数。点击更新后，类型、规格、长度、补偿和孔深会一次应用到全部目标；只有主动点击读取组件，面板才会载入已有螺丝的数据。

**屏幕字幕**

`选择目标不会覆盖面板模板`

随后显示：

`读取 = 载入参数 · 更新 = 应用模板`

**鼠标与剪辑提示**

- “模板摘要”和“已选摘要”分别用两个短框标注。
- 框选控制点时避免选中宿主实体，必要时先关闭 Gumball。
- 更新前后使用同一机位，便于观众比较规格变化。

---

### 2:50–3:35｜非破坏导出到 Rhino

**画面操作**

1. 选择需要输出的两块宿主板材。
2. 左击底部“放入 Rhino”图标。
3. 展示跟随鼠标的布尔成果预览，在空白位置单击放置。
4. 将原始参数化模型与新生成的普通 Brep 成果并排显示。
5. 对成果执行剖切或隐藏前板，确认沉孔、通孔和咬合孔。
6. 鼠标回到“放入 Rhino”图标，显示左右键 Tooltip。

**旁白**

> 设计确认后，选择宿主并左击“放入 Rhino”。插件在内存副本上重新生成切割体和布尔结果，单击即可把普通 Brep 成果放回场景。左侧的原始组件没有被修改，后续仍可继续调整。
>
> 如果需要渲染表达，可以右击同一个图标，同时输出带材质的紧固件实体。STEP 和 STL 导出也使用同一套实时切割参数，因此视口预览与最终成果保持一致。

**屏幕字幕**

- `导出布尔副本，原始模型保持可编辑`
- `左击：布尔宿主 · 右击：宿主＋紧固件实体`

**鼠标与剪辑提示**

- 原始模型标注“参数化组件”，输出结果标注“普通 Brep”。
- 右击功能只做 Tooltip 和 2 秒渲染成果闪示，不重复完整导出流程。
- 剖切画面停留至少 3 秒。

---

### 3:35–4:00｜总结与功能延伸

**画面操作**

1. 以每个约 2 秒的快切展示：
   - “螺母固定”模式及配套螺母槽。
   - 尼龙防松螺母。
   - 热熔螺母及导角安装孔。
   - 紧固件统计窗口与 Excel 汇总。
2. 回到两板案例的最终渲染视图。
3. 显示版本号、GitHub Release 地址或二维码。

**旁白**

> 除了螺纹咬合，插件还支持只咬合加强、螺丝加螺母、普通和尼龙防松螺母，以及自定义尺寸热熔螺母。控制点、模板、批量更新、统计和导出组成了一套完整的紧固件工作流。这就是参数化紧固件 0.30.3。

**屏幕字幕**

`智能放置 · 参数化编辑 · 批量更新 · 非破坏导出`

结尾字幕：

`参数化紧固件 0.30.3 · Rhino 8 Windows`

**鼠标与剪辑提示**

- 高级功能使用快切，不展开参数细节。
- 最终画面保留 3 秒，加入 Release 链接或二维码。
- 背景音乐在结尾字幕出现时降低约 4 dB，保证最后一句清晰。

## 录制准备清单

### Rhino 场景

- 两块独立的封闭板材实体，沿螺丝轴线前后排列。
- 前板厚度建议 `4–6 mm`，两板间保留少量可见间距。
- 后板厚度足以容纳 M3 咬合孔。
- 预先放置 3 个控制点位置，用于批量更新镜头。
- 场景中留出一块空白区域，用于放置“放入 Rhino”的布尔成果。

### 示例参数

| 参数 | 初始值 | 快速编辑后 | 批量演示 |
| --- | ---: | ---: | ---: |
| 类型 | 杯头 | 杯头 | 杯头 |
| 规格 | M3 | M3 | M4 |
| 长度 | 20 mm | 25 mm | 25 mm |
| 嵌入 | 齐平 | 齐平 | 齐平 |
| 装配方式 | 螺纹咬合 | 螺纹咬合 | 螺纹咬合 |
| 孔径修正 | 0.20 mm | 0.20 mm | 0.20 mm |
| 咬合缩减 | 0.35 mm | 0.35 mm | 0.35 mm |
| 咬合深度 | L+1D | L+1D | L+1D |

### 录屏设置

- Rhino 使用 1920×1080 或更高分辨率录制。
- 主面板保持在右侧，宽度以能完整显示参数但不过度占据视口为准。
- 开启鼠标点击提示；对象捕捉图标只保留本次需要的捕捉类型。
- 快速小窗保持开启，录制前确认不会遮挡控制点和螺丝本体。
- 准备普通着色、半透明预览和剖切三种显示状态。
- 导出成果使用独立图层和清晰命名，方便画面中快速显隐。

### 剪辑素材

- 原始双板模型静帧。
- 智能放置动态预览完整录屏。
- 快速编辑前后同机位对比。
- 批量更新前后同机位对比。
- 布尔成果剖切视图。
- 螺母固定、防松螺母、热熔螺母和统计窗口各一段 2 秒素材。
- GitHub Release 链接或二维码结尾卡。
