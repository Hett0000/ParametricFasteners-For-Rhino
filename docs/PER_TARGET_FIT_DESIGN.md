# 每宿主孔配合实现设计

## 1. 目标场景

一颗螺丝沿同一轴线连接两个或更多打印零件：

- **穿过宿主**：螺丝杆应自由穿过，不与材料形成螺纹咬合，圆孔大于公称直径。
- **咬合宿主**：螺丝直接拧入打印材料形成咬合，圆柱预孔小于公称直径。

一个孔组件代表一颗紧固件的规格、轴线和放置入口，但不再代表一个可用于所有宿主的统一切割体。

## 2. 尺寸语义

设：

- `D_nominal`：螺丝公称直径。
- `D_standard(fitClass)`：标准紧配、普通或宽松通孔直径。
- `C_printer`：打印机孔径修正，正值扩大 CAD 孔以补偿 FDM 孔偏小。
- `C_binding`：该宿主绑定的有符号微调，默认 0。
- `I_bite`：直接咬合缩量，存储为正数，必须来自按规格校准的打印配置或显式输入。

穿过通孔：

```text
D_clearance = D_standard(fitClass) + C_printer + C_binding
```

咬合预孔：

```text
D_engagement = D_nominal - I_bite + C_printer + C_binding
```

验证条件：

```text
D_clearance > D_nominal + documentTolerance
0 < D_engagement < D_nominal - documentTolerance
I_bite > 0
```

`I_bite` 不是国标内螺纹小径，也不是强度保证。首版孔壁保持光滑圆柱，由实际螺丝在打印材料中形成咬合。若用户计划打印后使用丝锥，应在后续版本增加独立的“攻丝预孔”策略，不能与直接咬合共用名称或默认值。

## 3. 数据模型

```csharp
enum ShaftFitRole
{
    Clearance,
    ThreadEngagement
}

sealed record HoleTargetBinding(
    Guid TargetObjectId,
    ShaftFitRole ShaftFitRole,
    ClearanceFitClass? FitClass,
    double? DirectBiteReductionMm,
    double? XyCorrectionOverrideMm,
    DepthMode DepthMode,
    double? BlindDepthMm,
    bool IncludeHeadSeat);
```

持久化规则：

- `TargetObjectId` 在一个组件内唯一。
- `FitClass` 仅在 `Clearance` 时存在。
- `DirectBiteReductionMm` 仅在 `ThreadEngagement` 时存在。
- 螺钉组件最多一个绑定可设置 `IncludeHeadSeat = true`。
- 头部承座默认分配给入口侧第一个穿过宿主；用户可以改选。
- 删除或替换宿主时只使对应绑定失效，不丢失其他绑定参数。

## 4. 交互设计

放置轴线并选择多个宿主后，面板显示表格：

| 宿主 | 轴孔角色 | 配合/咬合缩量 | 最终孔径 | 深度 | 头部承座 | 状态 |
| --- | --- | --- | --- | --- | --- | --- |
| 零件 A | 穿过通孔 | 普通 | 计算值 | 穿过宿主 | 是 | 有效 |
| 零件 B | 咬合预孔 | 配置值 | 计算值 | 盲孔/穿过宿主 | 否 | 有效 |

- 初始入口宿主默认为“穿过通孔”；后续宿主不自动猜测为咬合，用户必须明确选择角色。
- 咬合缩量没有校准值时，该行显示“需要校准”，并禁用最终确认。
- 预览中通孔切割体使用橙色，咬合预孔使用紫色；选中表格行时只强调该宿主的切割体。
- 最终孔径始终直接显示，避免用户只看到补偿值却不知道真实结果。

## 5. 几何与导出算法

1. 用组件轴线分别计算每个宿主沿轴向的进入和离开区间。
2. 根据 `ShaftFitRole` 计算该宿主最终轴孔直径。
3. 生成只覆盖该宿主区间及容差余量的闭合圆柱切割体。
4. 若该绑定承担头部承座，将沉孔或沉头几何并入该绑定的切割体。
5. 将预览几何按绑定分组缓存；任何规格、配置、角色或宿主变化只失效相关缓存。
6. 导出时从参数重新生成，不使用缓存或文档中的显示 Brep。
7. 对每个宿主副本只应用属于自己的切割体，再进入 STEP/STL 写出流程。

这样即使 A、B 两个实体相贴或重叠，A 的大通孔切割体也不会参与 B 的布尔，B 的小预孔切割体也不会参与 A 的布尔。

## 6. M1.6 支持

- 规格库、下拉选择、序列化、公式测试和几何测试均加入 M1.6。
- 数据行必须包含公称直径、粗牙螺距、三档通孔尺寸及对应头部/螺母尺寸；禁止通过 M2 比例缩放生成。
- 咬合缩量必须按 M1.6 单独校准，不能沿用 M2 或全局固定毫米值。
- 文档绝对容差大于最小切割尺寸的 `1/50` 时警告，大于 `1/20` 时阻止放置和导出。
- STL 最大边长不大于最小有效孔径的 `1/20`，否则阻止以当前精度导出。

## 7. 边界与后续扩展

首版不支持同一个宿主沿同一轴线先通孔、后咬合的分段孔，也不生成真实螺旋牙型。未来扩展应新增轴向区段模型或独立 `EngagementStrategy`，不能通过让同一个宿主重复绑定两次来绕过唯一性规则。

建议后续提供校准试片生成器：一次生成同规格、不同咬合缩量的孔阵列，用户试拧后把选中值保存到打印机/材料配置中。
