# 参数化紧固件 0.38.7

## 更新常驻可用

- 主面板“应用更新”保持可点击，不再因选择事件延迟或更新完成后的重选过程变灰。
- 点击更新时直接读取 Rhino 当前选择；无选择时给出提示，损坏或待重绑组件仍由事务预检安全阻止。
- 更新提交期间使用内部重入保护，重复点击不会创建第二次事务。
- 更新完成后恢复并重新同步控制点选择，可继续将当前面板模板应用到同一批组件。

## 快捷编辑操作栏

- 底部按钮合并为单排 `读取｜取消｜应用｜删除`，四项按窗口可用宽度均分。
- 删除按钮默认使用低强调危险配色；首次点击后显示“确认删除”并切换为高对比红色。
- 两秒内再次点击才删除完整参数化组件；宿主实体不会被删除。
- 浅色、深色及运行时主题切换均使用对应的危险操作颜色。

## 兼容性

- 插件版本：`0.38.7`
- 组件 schema：`v21`
- 模板 schema：`v5`
- 模板库 schema：`v2`
- 不修改既有组件参数、宿主绑定、几何或导出规则。
