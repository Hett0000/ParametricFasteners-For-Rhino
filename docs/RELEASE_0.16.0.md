# 参数化紧固件 0.16.0

## 本次更新

- 修复六角螺母错误使用圆柱轴孔切割体的问题，改为按标准对边和厚度生成六角盲槽。
- 新增热熔螺母类型，可设置螺纹规格、长度、外径和带符号直径补偿。
- 热熔安装孔使用精确盲孔底和自动 `45°×0.5 mm` 入口导角。
- 六角螺母和热熔螺母改为单击封闭宿主面放置。
- Rhino、STEP、STL 导出实时使用组件参数重建螺母切割体。
- 统计与 Excel 支持按热熔螺母的规格、长度和外径汇总。

## 数据兼容

- 组件 schema 升级为 v6。
- schema v5 六角螺母自动保留首选宿主并迁移为单一安装槽绑定。
- 组件 ID、控制点、宿主 ID、预览/布尔开关和 `RhinoMM.*` 元数据键保持兼容。

## 尺寸说明

- 六角槽最终对边为：标准对边 + 孔径修正 + 绑定附加修正。
- 热熔孔最终直径为：外径 + 切割补偿；负值形成过盈，正值放宽。
- 热熔螺母尺寸依赖具体产品，插件不提供未经厂家验证的外径与长度预设。
