# 参数化紧固件 0.20.0

## 新增

- “放置/绑定”默认升级为智能所见即所得放置。
- 虚拟紧固件、轴孔、头部切割体和安装槽随鼠标实时预览。
- 支持自由面落点以及端点、中点、圆心、交点、节点和 Point 对象捕捉。
- 沿螺杆轴线自动识别穿过体与螺纹咬合体，并以蓝色、橙色轮廓区分。
- 命令行增加自动、全部通孔、全部咬合、翻转方向和经典放置选项。
- 新增 `ParametricFastenersPlaceClassic` 经典放置命令。

## 交互

- 单击生成一颗独立组件后继续跟随鼠标，可连续放置。
- Enter、右键或 Esc 结束；本次命令已生成的组件全部保留并由一次 Undo/Redo 管理。
- 自动识别遇到重叠实体、相同进入深度或无有效宿主时不猜测，显示原因并阻止写入。
- 六角螺母和热熔螺母沿用单宿主规则，并获得相同的动态预览和连续放置体验。

## 兼容性

- `ParametricFastenersPlace` 改为智能入口。
- `RhinoMMPlaceHole` 保持原经典流程，现有脚本和模型继续兼容。
- 组件 schema 保持 v7；组件 ID、绑定数据和 `RhinoMM.*` 元数据键不变。
