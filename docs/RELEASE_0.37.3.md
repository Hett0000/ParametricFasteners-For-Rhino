# 参数化紧固件 0.37.3：只咬合顶部对位孔

## 新功能

- “只咬合”模式增加顶部正补偿对位孔，方便螺丝先进入孔口再进入咬合段。
- 新组件默认对位深度 `3.00 mm`、直径正补偿 `0.20 mm`；深度设为 `0` 即完全关闭。
- 对位直孔与咬合孔之间采用夹角 `60°` 的直线圆台过渡。
- 对位孔直径按 `D + 对位正补偿 + 宿主附加修正` 计算；咬合孔继续按 `D − 咬合缩减 + 宿主附加修正` 计算。

## 倾斜宿主与可靠性

- 对位深度从完整孔口圆周的最深入口起算，倾斜或曲面宿主不会在浅侧缩短有效对位段。
- 宿主必须容纳完整直段、60°圆台和至少一个文档公差的咬合段；空间不足时整次操作零写入。
- 轻量摆放预览显示对位直段和圆台轮廓；点击后由共享精确管线生成最终几何。
- 组件代理、文档修复以及 Rhino、STEP、STL 输出使用同一切割结果。

## 兼容

- 组件 schema 升级为 v20，模板 schema 升级为 v5。
- v19及更早组件、v4及更早模板迁移后对位深度为 `0`，保持原有几何。
- 插件 GUID、组件 ID、绑定 ID和公开命令不变。
