# 参数化紧固件 0.38.6

## 快捷编辑窗口

- 错误和警告固定为单行省略显示，完整内容保留在 Tooltip 和 Rhino 命令行。
- 窗口使用实际首选高度，操作按钮不会再被长信息遮挡。
- 活动视口高度不足时自动收起参数字段，保留摘要和全部操作。

## 操作面板

- “更多”面板固定显示在活动视口上方居中。
- 面板位置受当前显示器工作区约束，支持多显示器和高 DPI。
- 重复打开时激活已有面板，不再产生屏幕外的重复窗口。

## 智能放置性能

- 鼠标移动阶段只做前表面拾取和紧固件本体显示，不执行轴向宿主扫描、角色分类、切割几何或布尔预检。
- 本体使用局部代理缓存和 `PushModelTransform` 绘制，不再逐帧复制 Brep。
- 鼠标输入按约 16 ms 合并，规格和长度变化无需移动鼠标即可刷新。
- 单击后仍执行完整宿主识别、几何准备和事务提交，最终模型与导出精度不变。

## 兼容性

- 插件版本：`0.38.6`
- 组件 schema：v21
- 模板 schema：v5
- 模板库 schema：v2
- 插件 GUID、组件数据和公开命令保持不变。
