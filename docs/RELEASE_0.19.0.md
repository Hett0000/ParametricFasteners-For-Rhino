# 参数化紧固件 0.19.0

## 新增

- 主面板和紧固件统计窗口自动跟随 Rhino 浅色、深色界面。
- 面板打开期间切换 Rhino 外观设置即可即时刷新，无需重启 Rhino。
- 新增语义主题调色板，统一画布、卡片、边界、主次文字、禁用状态和状态提示。
- 深色模式增加独立的 24、36、48 像素浅色线性图标资源。

## 改进

- 深色模式使用分层深灰表面，消除白色卡片和深色输入框之间的割裂。
- 类型、规格、长度卡片及底部操作栏在浅色和深色模式下保持一致的选中、主操作和禁用状态。
- 调色板会校正文本与必要边界的对比度；输入框、下拉框、复选框、滚动条和折叠控件继续使用 Rhino 原生样式。

## 兼容性

- 组件 schema 保持 v7。
- 几何、材质、导出、组件 ID、`RhinoMM.*` 元数据键和既有 3DM 文件不变。
