# 参数化紧固件 0.35.0 发布说明

## 全插件视觉统一

- 主面板、组件导航器、装配检查器、维护中心、重绑向导、输出中心、自定义标准件库、批量预检、统计、模板、交付信息和全局显示采用统一主题与布局骨架。
- 支持 Rhino 浅色、深色及运行时主题切换；窗口使用系统字体、语义状态色和一致的 4/8/12 DIP 间距。
- 固定摘要与操作栏不参与纵向拉伸，表格和内容区按可用空间伸缩，长文本进入详情或 Tooltip。

## 反馈、进度与取消

- 放置、更新、刷新和重绑成功后提供克制的短状态与视口定位反馈。
- 装配检查器改为每文档单一非模态窗口，模型变化后自动标记报告过期。
- 批量点位预检、导航器深度检查、重绑候选分析和输出中心显示阶段、数量和进度，并支持安全取消。
- 输出取消或失败时清理临时目录，不留下部分交付文件。

## 窗口改进

- 自定义标准件库支持宽屏双栏与窄屏单栏布局。
- 组件导航器改用固定筛选、弹性表格、固定详情和操作区。
- 维护中心使用三个独立紧凑动作卡片，显式重绑继续保持模态事务确认。
- 主面板成功提示约 1.2 秒后恢复选择摘要，底部八图标与既有命令行为保持不变。

## 兼容性

- 插件版本：`0.35.0`
- 组件 schema：`v17`（未变化）
- 模板 schema：`v2`（未变化）
- 用户标准件库 schema：`v1`（未变化）
- 插件 GUID、组件 ID、绑定 ID、命令、几何和现有 3DM 数据保持兼容。
