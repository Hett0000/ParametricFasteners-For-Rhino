# 参数化紧固件 0.10.0

## 本次更新

- 增加“紧固件统计”窗口，可在“当前选择”和“全部组件”之间明确切换。
- 支持框选一个或多个控制点后统计；全量模式扫描当前 Rhino 文档中的全部有效控制点组件。
- 汇总按类型、规格和长度分组；六角螺母忽略长度，同规格螺母合并计数。
- 增加“导出 Excel”按钮和工具列命令，保存前显示统计预览。
- Excel 工作簿包含“汇总”和“明细”两个工作表，记录数量、基础参数、宿主数量、孔深模式、控制点坐标和组件 ID。
- Excel 使用内置 OOXML 写入器生成，不增加第三方运行依赖；保存采用同目录临时文件和原子替换。
- 数据损坏或缺少实际控制点的残留组件不计入统计，并提示运行“刷新 / 清理”。

## 兼容性

- 插件版本：0.10.0。
- 持久化 schema：v5（未变化）。
- 插件 GUID、组件 ID、`RhinoMM.*` 元数据和旧命令保持兼容。

## 新命令

- `ParametricFastenersStatistics`
- `ParametricFastenersExportExcel`
