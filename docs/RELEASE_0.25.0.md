# 参数化紧固件 0.25.0

## 新功能

- 内六角杯头螺丝增加可选的悬垂沉孔双层交叉架桥补偿。
- 第一层通过与最终补偿杆孔相切的平行线保留两侧圆弧桥，第二层生成垂直方形桥，随后恢复圆孔。
- 架桥层高可在 0.05–1.00 mm 内设置，默认每层 0.20 mm；放置预设可跨 Rhino 会话保存。
- 智能摆放运行期间修改开关或层高，虚拟切割体即时刷新。

## 一致性与安全

- 组件更新、刷新、复制生命周期以及 Rhino、STEP、STL 导出统一使用共享切割服务。
- 宿主空间不足、层高不合法或补偿后的杆孔过大时停止写入并给出明确原因。
- 组件 schema 升级为 v11；旧组件迁移后默认关闭架桥，保留原有几何。

## 验证

- 核心测试覆盖 0.12、0.16、0.20、0.28 mm 层高、最终补偿孔径、迁移和批量模板。
- Release 构建继续面向 Rhino 8 / .NET 7，并执行 Rhino `Compat.exe` 检查。
