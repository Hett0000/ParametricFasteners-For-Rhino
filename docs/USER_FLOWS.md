# 用户流程

## 1. 首次使用

1. 运行 `RhinoMMPanel` 打开右侧停靠面板。
2. 检查当前 3DM 是否设置单位；未设置时插件阻止继续并引导到文档单位。
3. 选择“标准尺寸”或新建打印配置，输入 XY 和 Z 增量。
4. 插件记住上次使用的配置，但既有孔组件继续使用各自保存的快照。

## 2. 面上放置孔组件

1. 选择紧固件类型、规格、配合等级和深度模式。
2. 点击“在面上放置”。
3. 选择封闭实体的一个子面，再在面上选择入口点。
4. 插件显示切割体、轴线、相交状态和自动判断的向内方向。
5. 必要时翻转方向、调整盲孔深度或旋转六角槽。
6. 确认后创建孔组件，显式绑定所选宿主并保存参数。
7. 命令保持上次规格，允许继续放置，按 Esc 退出。

## 3. 从起点和方向放置

1. 点击“起点放置”。
2. 选择一个或多个宿主实体。
3. 选择入口起点，再选择第二点确定轴向。
4. 插件显示所有绑定宿主的相交检查。
5. 调整参数并确认，创建一个绑定多个宿主的孔组件。

## 4. 编辑孔组件

1. 选择半透明切割体，或运行 `RhinoMMEditHole` 后选择组件。
2. 面板载入预设、规格、补偿、深度、方向和绑定状态。
3. 修改参数后实时更新预览。
4. 点击“应用”，插件在一个 Undo 记录中替换切割几何并更新 UserData。
5. 如果最终尺寸非法或与宿主不相交，“应用”保持禁用并解释原因。

## 5. 重新绑定

1. 失效组件在视口和面板中显示警告状态。
2. 运行 `RhinoMMRelinkHole`，选择组件和新的一个或多个封闭实体。
3. 插件验证当前切割体与每个宿主的关系。
4. 验证成功后保存新 GUID；几何位置默认不改变。

## 6. 导出打印文件

1. 点击“导出打印文件”或运行 `RhinoMMExportPrint`。
2. 选择需要导出的宿主实体；没有孔组件的选中实体按原样输出。
3. 选择 STEP/STL、输出单位和 STL 网格精度。
4. 插件预检单位、闭合状态、绑定、尺寸和相交关系。
5. 插件在临时文档中复制实体、重新生成切割体并执行布尔差集。
6. 全部成功后写入目标路径；失败时不写文件，并选中相关组件。
7. 当前 3DM 中的宿主和孔组件始终保持不变。

## 7. 关键异常

| 情况 | 行为 |
| --- | --- |
| 文档未设置单位 | 阻止放置和导出，要求设置单位 |
| 选择开放 Brep、Mesh 或 SubD | 拒绝选择并说明首版支持范围 |
| 补偿导致尺寸小于等于零 | 标红字段，禁用确认 |
| 曲面法向判断不确定 | 保留预览，要求用户明确确认或翻转 |
| 组件没有有效宿主 | 标记失效，提供重新绑定入口 |
| 绑定宿主不与切割体相交 | 阻止导出，定位到组件 |
| 布尔返回多个意外碎片或失败 | 取消整个导出并报告失败阶段 |
| 目标文件已存在 | 仅在全部计算成功后请求覆盖或替换 |
