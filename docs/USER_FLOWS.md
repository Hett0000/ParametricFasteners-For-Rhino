# 用户流程

## 智能装配与批量放置（0.38.0）

1. 在主面板设置类型、规格、装配方式和切割策略；当前模板装配方式始终优先。
2. 右击“放置”图标，选择 Rhino Point、点云、圆/圆弧、开放曲线端点、圆形 Brep 边或平面圆孔内环。
3. 预检窗口逐项显示宿主测量、当前长度、建议长度和“采用长度”。采用长度可从常用值下拉选择，也可输入自定义值。
4. 点击“全部采用建议”可快速接受；点击“恢复模板长度”可取消本批长度建议。
5. 当前装配方式不可行时，只有全部点位支持同一种替代方式，窗口才提供整批切换入口；切换后会重新预检，不会直接写入。
6. 点击“创建 N 项”后，插件重新读取宿主和参数并完成最终预检；全部通过后一次 Undo 创建整批组件。
7. 框选多个已有控制点时，可在批量浮动条勾选“长度自适应”，以主面板类型、规格和孔策略为模板，为每颗螺丝独立选择适合其宿主的长度。
8. “更多… → 智能装配建议”打开装配检查器；可查看测量依据、覆盖采用长度并批量应用。

### 自由面放置拾取

- 视口客户端坐标会先转换为屏幕坐标，再建立近裁剪面到远裁剪面的射线。
- 无 Osnap 时选择鼠标下方最前方的可见、未锁定封闭实体面；有 Osnap 时捕捉点仍必须属于该前表面宿主。
- 候选包围盒只用于加速，最终必须通过精确 Brep 相交；多个实体表面深度重合时停止并提示经典放置。

## 只咬合顶部对位孔（0.37.3）

1. 在“装配方式”中选择“只咬合”。
2. 设置“对位深度 mm”和“对位正补偿 mm”。默认分别为 `3.00` 和 `0.20`。
3. 深度为 `0` 时不生成顶部对位结构；大于 `0` 时先形成正补偿直孔，再以60°圆台过渡到原咬合孔。
4. 点击放置或更新。倾斜表面会按完整孔口最深入口计深；宿主无法容纳完整结构时操作取消并显示原因。

## 1. 首次使用

1. 运行 `ParametricFasteners` 打开“参数化紧固件”右侧停靠面板；旧命令 `RhinoMMPanel` 继续兼容。
2. 检查当前 3DM 是否设置单位；未设置时插件阻止继续并引导到文档单位。
3. 选择“标准尺寸”或新建打印配置，输入 XY 和 Z 增量。
4. 插件记住上次使用的配置，但既有孔组件继续使用各自保存的快照。

## 2. 面上放置孔组件

1. 选择紧固件类型、规格、配合等级和深度模式。
2. 点击“在面上放置”。
3. 选择封闭实体的一个子面，再在面上选择入口点。
4. 插件显示切割体、轴线、相交状态和自动判断的向内方向。
5. 必要时调整盲孔深度或旋转六角槽；需要手工指定轴向时改用经典放置。
6. 确认后创建孔组件，显式绑定所选宿主并保存参数。
7. 命令保持上次规格，允许继续放置，按 Esc 退出。

## 3. 从起点和方向放置

1. 点击“起点放置”。
2. 选择一个或多个宿主实体。
3. 选择入口起点，再选择第二点确定轴向。
4. 插件列出所有绑定宿主；用户将入口零件设为“穿过通孔”，将承力零件设为“螺纹咬合预孔”。
5. 设置通孔孔径修正和咬合缩减；两者均以公称直径为基准并分别作用于对应孔型。
6. 指定唯一的头部承座宿主，并检查每个宿主的最终孔径和切割深度。
7. 咬合孔可选择“完全贯穿”“螺杆长度 + 1D”或“螺杆长度 + 自定数值”；自定数值是追加毫米，孔底为嵌入深度、螺杆长度和追加值之和。
8. 插件用不同颜色显示各宿主专属切割体及相交检查。
9. 调整参数并确认，创建一个绑定多个宿主、每个绑定有独立角色的孔组件。

### 典型两零件连接

1. 螺丝公称直径为 `D`，轴线依次穿过零件 A 和零件 B。
2. 零件 A 设置为“穿过通孔”，最终孔径大于 `D`，并可承担头部沉孔/沉头。
3. 零件 B 设置为“螺纹咬合预孔”，最终孔径小于 `D`，螺丝直接拧入打印材料形成咬合。
4. 导出时分别对 A、B 的副本使用不同直径的切割体；即使两实体接触，也不允许共享同一个轴孔切割 Brep。

## 4. 编辑与批量更新组件

1. 先在面板设置准备应用的类型、规格、长度、嵌入深度、补偿和咬合孔深度。
2. 在 Rhino 视口选择一个控制点或框选多个控制点；选择只改变顶部“已选”摘要，不会覆盖面板模板。
   - 单选螺丝使用紧凑摘要，例如：`沉头 M3*30 +1切割 通1/咬1`。
3. 点击“更新”，插件把当前模板事务式应用到全部选中组件；任一组件预检失败时整批不写入。
4. 若需要查看或微调已有组件，选中其控制点后点击“读取组件”；只有该操作会把组件数据载入面板。
5. 单组件读取后，顶部孔深、预览和导出布尔统一控制该组件全部同角色宿主。
6. 更新后重新选中新控制点，面板模板保持不变，便于继续框选下一批。
7. 组件 ID、位置、宿主、绑定、组关系和未明确覆盖的预览/布尔开关保持不变。

### 螺丝头嵌入与离面

1. 三类螺丝使用“嵌入/离面 mm”：正值表示头部进入宿主，`0` 表示头底贴面，负值表示头底离开宿主表面。
2. 例如 M3×20 输入 `-2` 后，头底离面 2 mm，控制点仍在原安装面，螺杆末端的实际轴向位置为 18 mm。
3. 负值会缩短螺杆进入宿主的有效长度；智能更新会重新检查是否穿过第一宿主、到达咬合宿主或仍能容纳配套螺母。
4. 离面状态只生成螺杆孔，不生成沉孔、沉头承座、头部通道或杯头架桥。
5. 离面距离必须小于螺杆长度；六角螺母仍只接受非负嵌入，热熔螺母使用自身的长度和深度补偿参数。

## 5. 接管模型中的普通螺丝

1. 选择一个普通螺丝实体、拉伸体或块实例，点击面板中的“接管为 RhinoMM 螺丝”，也可运行 `RhinoMMAdoptFastener`。
2. 插件检查是否已有 RhinoMM 数据；已有时直接读取并进入编辑，不重复转换。
3. 对普通对象分析轴线、杆径和头部轮廓，列出可能的预设和规格；无法可靠匹配时进入手动选择。
4. 用户确认类型、规格、入口点和轴向，并查看简化无螺纹代理与原对象叠加预览。
5. 用户选择宿主并设置穿过通孔/咬合预孔角色。
6. 确认后插件默认隐藏原对象，在相同位置创建 RhinoMM 组件，并保存源对象 GUID 以便撤销或追溯。
7. 若用户显式选择“删除源对象”，操作仍必须可通过 Undo 恢复；该选项默认关闭。

## 6. 重新绑定

1. 失效组件在视口和面板中显示警告状态。
2. 运行 `RhinoMMRelinkHole`，选择组件和新的一个或多个封闭实体。
3. 为每个新宿主选择“穿过通孔”或“螺纹咬合预孔”，并重新指定头部承座宿主。
4. 插件验证各自专属切割体与宿主的关系。
5. 验证成功后保存新绑定；几何轴线默认不改变。

## 7. 导出打印文件

1. 点击“导出打印文件”或运行 `RhinoMMExportPrint`。
2. 选择需要导出的宿主实体；没有孔组件的选中实体按原样输出。
3. 选择 STEP/STL、输出单位和 STL 网格精度。
4. 插件预检单位、闭合状态、绑定角色、每宿主最终孔径、尺寸和相交关系。
5. 插件在临时文档中复制实体，逐宿主重新生成专属切割体并执行布尔差集。
6. 全部成功后写入目标路径；失败时不写文件，并选中相关组件。
7. 当前 3DM 中的宿主和孔组件始终保持不变。

## 8. 关键异常

| 情况 | 行为 |
| --- | --- |
| 文档未设置单位 | 阻止放置和导出，要求设置单位 |
| 选择开放 Brep、Mesh 或 SubD | 拒绝选择并说明首版支持范围 |
| 补偿导致尺寸小于等于零 | 标红字段，禁用确认 |
| 穿过通孔最终直径不大于公称直径 | 阻止确认，提示增加配合孔径或修正值 |
| 咬合预孔没有校准缩量 | 阻止确认，要求选择配置或显式输入 |
| 咬合预孔最终直径不小于公称直径 | 阻止确认，提示当前设置无法形成咬合 |
| 同一宿主被重复分配两种轴孔角色 | 合并为一行并要求用户选择唯一角色 |
| 多个宿主被指定为头部承座 | 只允许保留一个，并要求用户确认入口侧宿主 |
| 选中一个 RhinoMM 代理或切割体 | 读取同一组件并进入编辑，不创建副本 |
| 选中宿主且关联多个组件 | 显示列表，要求用户明确选择要编辑的组件 |
| 普通螺丝几何匹配多个规格 | 显示候选及偏差，禁止自动确认 |
| 普通对象无法识别为螺丝 | 允许手动指定预设、规格、入口和轴向 |
| 自动更新任一几何失败 | 回滚整个修改，保留旧代理、切割体和参数 |
| 曲面法向判断不确定 | 阻止智能写入，并提示使用经典放置明确指定轴向 |
| 组件没有有效宿主 | 标记失效，提供重新绑定入口 |
| 绑定宿主不与切割体相交 | 阻止导出，定位到组件 |
| 布尔返回多个意外碎片或失败 | 取消整个导出并报告失败阶段 |
| 目标文件已存在 | 仅在全部计算成功后请求覆盖或替换 |
# 0.9.0 补充流程

## 捕捉点连续放置

1. 选择通孔宿主和咬合宿主一次。
2. 在放置方式中选择“捕捉点”。
3. 捕捉第一点并指定一次孔轴方向，插件立即生成第一颗紧固件。
4. 继续捕捉其他点；每次点击生成一个具有独立组件 ID 和控制点的新组件，方向沿用第一次设置并在封闭宿主表面自动校正为朝内。

## 智能所见即所得放置

1. 在面板设置紧固件类型、规格、长度和孔预设，点击底部“放置”图标。
2. 虚拟紧固件跟随鼠标；没有 Osnap 时落在鼠标所在实体面，存在端点、中点、圆心、交点、节点或 Point 时优先使用捕捉点。
3. 插件沿面法线朝实体内部扫描螺杆有效长度：单实体作为咬合体，多实体中最深处作为咬合体，其余作为穿过体。
4. 蓝色轮廓表示穿过体，橙色轮廓表示咬合体；半透明几何显示实际轴孔、沉头或安装槽。
5. 可在命令行切换自动、全部通孔、全部咬合或经典放置；无效和歧义状态显示红色原因且禁止创建。
6. 单击生成后继续移动鼠标放置下一颗；Enter、右键或 Esc 结束，整批结果使用一次撤销。
5. 按 Enter、右键或 Esc 完成本批；已生成组件保留，整批可由一次 Undo 撤销。

## 模板式选择更新

1. 面板第一行始终显示当前模板；第二行显示单选、多选、规格分布和宿主数量。
2. 场景选择永远只指定更新目标，不载入组件参数。
3. 设置目标类型、规格、长度、嵌入深度、孔补偿和咬合孔深度后直接点击“更新”。
4. “读取组件”是唯一把已有组件参数载入面板的入口。
5. 当前选择中存在损坏或待重绑组件时，更新禁用并提示先运行“刷新 / 清理”。

## 移动后的刷新修复

1. 正常 Move 会同步控制点、本体、切割模块、放置坐标和宿主 ID。
2. 若模型来自异常中断或旧事件未收尾，点击“刷新 / 清理”，插件按实际控制点位置重建。
3. 若宿主 ID 已变化，先选中移动后的普通宿主再刷新；只有唯一匹配时才自动重绑。
4. 无法唯一重绑时组件被保留并列入提示；只有控制点实际缺失的组件才删除。
# 0.10.0 统计与 Excel 流程

## 统计框选组件

1. 在 Rhino 视口中框选一个或多个紧固件控制点。
2. 点击面板或工具列中的“紧固件统计”。
3. 统计窗口默认选择“当前选择”，显示螺丝、螺母、总数和物料规格数。
4. 可切换为“全部组件”或点击“刷新统计”重新读取当前文档。

## 导出 Excel

1. 点击“导出 Excel”，先在统计窗口确认“当前选择/全部组件”和汇总数量。
2. 点击“保存 Excel”并选择文件位置。
3. 工作簿生成“汇总”和“明细”两个工作表；取消保存不会生成文件，写入失败不会留下临时文件。
4. 缺少有效控制点的组件不导出，窗口提示先运行“刷新 / 清理”。

# 0.11.0 面板与统计流程

1. 新建状态下，用户通过类型、规格和常用长度卡片设置参数；底部“放置 / 绑定”保持可用。
2. 单选或框选有效控制点后，“应用更新”按选择有效性启用；底部八个按钮始终采用统一图标颜色和次级背景。
3. 嵌入深度可输入数值，也可点击 `0` 恢复贴面或点击 `齐平` 使用当前头高。
4. 点击“紧固件统计”后，在统计窗口选择“当前选择”或“全部组件”。
5. 确认数量摘要和规格汇总后，点击唯一的蓝色“保存 Excel”按钮导出。

# 0.12.0 批量模块与紧凑操作流程

1. 框选多个控制点后，补偿模块区域分别显示通孔模板和咬合孔模板。
2. 修改模板后点击底部“更新”图标，所有匹配角色统一深度、预览和导出布尔设置。
3. 更新继续保留每颗组件自己的宿主、绑定和头部承座；任一预检失败时整批不写入。
4. 底部八个图标从左到右为放置、更新、维护、放入 Rhino、导出 STEP、统计、装配检查和更多，悬停显示完整说明。

# 0.25.0 杯头沉孔架桥流程

1. 选择“杯头”，设置规格、长度和大于 0 的嵌入深度。
2. 在“孔与切割”中开启“悬垂沉孔架桥”，按切片层高设置每层高度；默认值为 0.20 mm。
3. 智能摆放预览同时显示沉孔主体、第一层切线槽和第二层方孔。
4. 放置或批量更新前，插件校验最终补偿杆孔能否形成桥区，以及宿主在沉孔底部之后是否至少保留两层高度。
5. 放入 Rhino、STEP 和 STL 均重建相同的双层几何；关闭开关后恢复普通杯头沉孔。

# 0.26.0 只咬合与全局显示流程

1. 在螺丝“孔与切割”中开启“只咬合”，设置长度及所需咬合孔深。
2. 智能放置时单击加强筋宿主表面；插件只绑定该宿主，不创建通孔绑定。
3. 宿主无法完整容纳螺杆时按提示把长度缩短到建议值；螺杆范围内存在第二实体时调整位置或关闭模式。
4. 批量更新时框选控制点后直接应用当前“只咬合”模板，任一组件预检失败则整批不写入。
5. 在底部“更多…”选择“全局显示…”，拖动滑块实时预览；确定保存，取消恢复。

# 0.26.1 只咬合导出与紧凑面板

1. 开启“只咬合”后，面板隐藏无关的通孔模块，只保留咬合孔深度、咬合模块开关和加强筋模式。
2. “螺杆长度 + 自定数值”被选中时，追加深度使用独立紧凑行，不再与孔深下拉框挤在一行。
3. 放入 Rhino、STEP 或 STL 时，插件重新复核唯一咬合宿主，并实时生成启用的螺丝孔。
4. 旧组件由通孔切换为只咬合时，模块状态从原咬合设置继承，避免通孔关闭状态误关咬合孔导出。

# 0.26.2 旧只咬合组件自动修复

1. 打开含有 0.26.0 或 0.26.1 只咬合组件的文档，无需重新放置螺丝。
2. 导出时控制点元数据自动迁移到 schema v13，并从智能咬合模板恢复正确的导出布尔状态。

# 0.27.0 正常智能摆放与孔径校验

1. 正常自动模式下，鼠标点击面所属实体必须是第一宿主；螺杆需要完整穿出该实体并进入后方实体。
2. 未穿出第一宿主时按提示增加到最小长度，或切换“只咬合”；没有后方宿主时可调整位置、改用只咬合或全部通孔。
3. 面板直接显示 `通孔 Ø… · 咬合 Ø…`，不再选择紧配/标准/松配。
4. 更新旧组件时会切换到 v14 独立孔径公式；未更新的旧组件继续保持原导出孔径。
5. 咬合宿主进入面倾斜时无需额外加深：插件会自动从完整孔圆最早接触位置开始切割，同时保持设定孔底不变。
3. 若用户主动关闭“咬合孔模块 → 导出布尔”，新版本会同步保存到绑定和智能模板，之后仍尊重关闭状态。

# 0.28.0 尼龙防松螺母流程

1. 选择“六角螺母”，勾选“尼龙防松螺母”。
2. 选择 M2–M12；M2、M2.5 会显示“DIN 985 工程扩展、打印前核对实物”，M1.6不可选。
3. 使用 `0`、`全埋`或数值框设置嵌入深度；新建防松螺母默认全埋。
4. 在宿主封闭实体面上单击，插件按面法线朝内生成控制点、全高代理体和六角安装槽。
5. 切换样式或规格时，全埋状态跟随新总高；0和自定义毫米深度保持不变。
6. 放入 Rhino、STEP、STL均按最新防松尺寸实时生成六角槽；统计与 Excel 将其和普通螺母分开记录。

# 0.29.0 螺丝＋螺母装配流程

1. 选择杯头、沉头或六角头螺丝，在“装配方式”中选择“螺母固定”。
2. 设置孔径修正、螺杆末端露出量（默认 2 mm）、普通/尼龙防松配套螺母及螺母槽补偿。
3. 智能放置时点击第一宿主表面；插件沿螺杆轴线识别全部宿主，所有宿主生成正补偿圆孔。
4. 螺母外侧端面位于螺杆尖端之前“末端露出量”处，最深且与螺母范围相交的唯一宿主承担六角槽。
5. 六角槽从螺母内侧端面沿螺杆尖端方向贯穿宿主背面；倾斜或曲面背面按完整六角横截面覆盖范围切净。
6. 修改长度、露出量、螺母样式或槽补偿后，选中控制点点击“更新”，插件重新识别末端宿主并事务式重建。
7. 右击“放入 Rhino”可同时输出螺丝和配套螺母渲染实体；统计与 Excel 分别记录两件物料并共享组件 ID。

# 0.30.0 快速编辑、模板和重复操作

## 视口快速编辑

1. 在没有其他 Rhino 命令运行时单选一个有效控制点，约 250 ms 后控制点右下方显示快速编辑器。
2. 根据组件类型修改规格、长度、嵌入、装配方式、螺母样式、外径或深度补偿；半透明预览不会改动文档对象。
3. 按 Enter 或点击“更新”提交一次事务；按 Esc 关闭并放弃草稿。
4. 点击“读取”才把该组件载入主面板；普通快速编辑不会覆盖主面板模板。
5. “删除”需在 2 秒内二次确认，删除控制点后沿用现有级联删除和 Undo。

## 参数手柄

1. 单选控制点后运行 `ParametricFastenersEditHandles`，或在快速编辑器/“更多…”中进入。
2. 单击长度、嵌入、螺母露出或旋转手柄，再移动鼠标预览。
3. 再次单击或输入数值确认；当前手柄操作预检失败时原组件保持不变。
4. 长度吸附常用值，嵌入吸附 0 和齐平/全埋，末端露出吸附 0/2 mm，方向按 15°吸附。
5. Esc 退出手柄模式；每次确认只产生一次组件更新和一次 Undo。

## 最近使用、收藏和重复操作

1. 成功放置或更新后，模板自动进入最近记录；最多保留 5 条且相同参数自动去重。
2. 主面板模板栏可收藏当前参数，或从“最近/收藏”菜单载入模板；载入只改变面板模板，不修改场景选择。
3. “更多 → 模板管理…”支持重命名、复制、排序、删除及收藏 JSON 导入/导出。
4. `ParametricFastenersRepeatPlace`使用上一次成功放置快照启动智能摆放，不覆盖主面板。
5. `ParametricFastenersRepeatUpdate`使用上一次成功更新模板作用于当前选中的控制点，保持可空模块开关语义。

# 0.32.0 点集批量放置与组件导航器

## 点集批量放置

1. 先在主面板设置需要复用的紧固件模板。
2. 右击底部“放置”图标，或运行 `ParametricFastenersBatchPlace`。
3. 选择 Rhino Point、点云、开放曲线、圆或圆弧；开放曲线提取起终点，圆和圆弧提取中心。
4. 插件对每个点严格查找公差范围内的封闭实体面，并使用与智能放置相同的方向、宿主角色和切割服务预检。
5. 预检窗口顶部以绿色、黄色和红色显示有效、警告和失败数量；中间表格自动占满可用空间，选择行可定位，双击可缩放。
6. 默认只在全部点通过时允许创建；勾选“跳过失败点”后可以只创建有效和警告项。
7. 点击“创建”后每个点生成独立组件 ID，但整批只产生一次 Undo。取消或预检失败不会写入文档。

预检窗口高度会随点位数量调整；大量点位只在表格内纵向滚动。没有失败项时底部直接显示可创建数量；存在失败项时必须明确勾选“跳过失败点”才能继续。

批量点必须已经位于可用实体面上，不会自动投影到最近面。需要自由面点击时继续使用左击“放置”的智能交互。

## 组件导航器与问题中心

1. 运行 `ParametricFastenersNavigator`，或在主面板“更多…”中打开“组件导航器与问题中心…”。
2. 使用搜索框和类型、规格、装配方式、宿主、图层、状态筛选器缩小范围。
3. 单击一行只选择对应控制点并显示短问题，不读取或覆盖主面板模板；双击缩放到组件。
4. 点击“选择结果”才批量选择当前筛选范围，随后可在主面板继续处理。
5. “应用模板”把主面板当前模板事务式应用到筛选结果；“统计”和“导出”同样只作用于当前结果范围。
6. 日常状态检查不执行昂贵布尔。需要确认实际切割时点击“深度检查”，插件逐组件在内存副本上验证，可在组件之间取消且不修改模型。

问题状态包括正常、待重绑、参数无效、导出关闭、预览隐藏、数据损坏和深度布尔失败。文档对象变化或 Undo/Redo 后，导航器会使用最新索引自动刷新。

# 0.34.0 装配检查、维护与交付

## 装配检查与长度建议

1. 从“更多…”或组件导航器打开“装配检查”。
2. 选择检查范围并运行检查；错误、警告和提示按组件列出，双击问题可定位并缩放到控制点。
3. 在设置区调整最小壁厚、孔间实体和工具空间阈值；这些值只影响诊断，不会写入 3DM。
4. 存在长度建议时，在“采用长度 mm”列选择常用长度、当前值或建议值，也可直接输入 `0–1000 mm` 的自定义值；表格下方同步显示当前值、建议值、采用值和差值。
5. 可先修改多行，再点击“应用长度（N）”一次提交。插件会重新读取组件并完成整批几何预检，成功时只产生一次 Undo；任一组件失败时整批不写入。
6. 模型发生变化后长度输入和应用按钮会立即禁用；重新检查会按最新组件长度重建编辑行，不沿用旧临时输入。

## 快速刷新、重新绑定与清理

1. 点击原“刷新”入口打开维护中心。
2. 选择“快速刷新”时，只同步控制点位置、对象 ID、组关系和预览，不自动寻找新宿主。
3. 选择“重新绑定”时，在向导中逐项检查候选宿主的轴向区间、重叠和评分原因；确认映射后才提交。
4. 选择“清理残留”时，只删除已经没有实际控制点的插件对象；普通宿主和有效组件不会被删除。

## 输出中心

1. 从“更多…”打开“输出中心”，选择当前选择、指定图层或全部有效宿主。
2. 勾选 3DM、STEP、STL、Excel、CSV；需要渲染装配时可让 3DM/STEP 包含紧固件实体。
3. 选择项目名和目标目录后开始预检。阻断错误必须先修复；薄壁、孔距或工具空间警告可由用户确认继续。
4. 输出成功后得到 `<项目名>_交付_yyyyMMdd-HHmm` 文件夹。任一格式失败时不会留下部分文件。

## 交付信息和自定义标准件

1. 在组件导航器选择一个或多个组件，打开“交付信息”，填写装配编号、项目分组和备注；批量编号可设置前缀和起始序号。
2. BOM 的螺母固定组件会展开为螺丝和配套螺母两行，并共享组件 ID、装配编号和分组。
3. 从“更多…”打开“自定义标准件库”，先复制一个内置规格，再修改允许的尺寸、来源、修订和备注。
4. 点击“应用到模板”后进行放置或更新。组件会保存完整尺寸快照，因此接收方没有同一用户库也能继续编辑和导出。
5. 库定义修改后不会自动改变模型；选中旧组件并执行“使用库中最新版本更新所选组件”才会升级。
6. JSON 用于完整交换，CSV 用于尺寸表批量交换；导入冲突不会静默覆盖现有定义。

# 0.35.5 持久安装与迁移

1. 完全关闭 Rhino，将离线安装 ZIP 解压到本地文件夹。
2. 双击`安装参数化紧固件.cmd`；安装器通过 Rhino 自带 Yak 写入稳定用户包目录。

6. 正式用户不再从`artifacts/plugin`或临时目录直接选择 RHP；该目录只供开发调试。

# 0.36.0 文档健康与安全修复

1. 打开 3DM 后插件只在后台分段读取组件状态，不自动修复、重绑或删除对象。
2. 文档正常时不显示额外提示；发现异常时通过低干扰徽标和组件导航器区分“需维护、待重绑、损坏”。
3. 对“需维护”问题运行“维护 → 一键修复”。插件以控制点实际位置和控制点参数重新生成本体、切割体、组与显示引用。
4. “待重绑”问题必须打开重新绑定向导并确认宿主；插件不会根据有歧义的模型关系自动猜测。
5. “损坏”问题只提供定位、原因和处理建议。控制点 JSON 损坏、重复控制点或组件 ID 冲突不会从螺丝实体反向恢复。
6. 缺少控制点的孤立代理和切割模块仍使用独立“清理残留”，不会与一键修复混在同一操作中。
7. 旧组件缺少新派生签名时属于兼容状态，不计入故障；更新或执行一键修复后会补齐签名，并清理派生对象上的旧完整参数副本。

# 0.36.1 咬合孔入口倒角

1. 在主面板选择螺丝，并将装配方式设为“螺纹咬合”。
2. 在“孔与切割”中勾选“咬合孔入口倒角”，输入 `C` 值；默认建议值为 `0.50 mm`。
3. 智能摆放预览会同时显示主咬合孔和入口锥口；修改开关或 C 值后无需移动鼠标即可使用最新参数。
4. 垂直入口的大端直径等于最终咬合孔径加 `2C`；倾斜入口会自动扩大浅侧覆盖范围，最深侧仍至少保留设定 C 值。
5. 入口过薄、近切向或存在多个重叠区间时，插件会停止放置/更新并给出原因，不会退回包围盒估算。
6. 倒角不改变咬合孔底；完全贯穿、L+1D 和 L+自定值仍使用原来的孔深规则。
7. 倾斜平面入口小于45°时使用解析交线，浅侧会自然变宽；达到或超过45°时轴向45°锥体不能形成有限闭合切口，插件会给出明确提示。

# 0.36.3 双模式咬合孔入口倒角

1. 勾选“咬合孔入口倒角”后，在“轴向45°｜表面等距”中选择方式；两种方式共用当前 C 值。
2. 选择“轴向45°”时，倒角沿螺丝轴生成；平面、倾斜面和连续曲面继续使用 0.36.2 的入口求解。
3. 选择“表面等距”时，宿主入口平面和圆柱孔壁分别退让相同的 C，倾斜螺丝也会得到标准双边等距倒角。
4. 表面等距只接受单一连续平面孔口；曲面、跨面、靠近边缘或候选边环不唯一时，按提示切回“轴向45°”。
5. 模式或 C 值变化会立即刷新智能预览；点击放置、应用更新、一键修复和全部导出使用相同的最终切割体。
6. 模式切换不会改变完全贯穿、L+1D 或 L+自定值的孔底。

6. 框选多个控制点后使用批量条，可直接应用主面板当前模板、运行装配检查或进入维护。
7. 智能摆放自动采用面法线朝内方向；需要明确指定方向时使用经典放置。
8. 主面板顶部“创建模板”与“选择目标”互相独立；普通选择不会覆盖模板。

# 0.37.2 智能放置轻量预览

1. 启动智能放置后正常移动鼠标；插件显示真实尺寸的虚拟紧固件、宿主角色颜色和孔轮廓，不在悬停阶段生成完整切割体。
2. 调整规格、长度、嵌入、孔深、倒角或架桥参数后，即使不移动鼠标，轻量预览也会按最新模板刷新。
3. 单击目标位置时，插件才执行完整宿主确认和精确几何预检；成功后直接提交同一份准备结果。
4. 如果单击瞬间参数、宿主或文档发生变化，当前点位不会写入，预览刷新后再次单击即可。
5. 精确预检失败不会结束连续放置命令，之前已经生成的组件保持不变。
# 0.38.5 范围隔离导出与问题处置

- 选择需要交付的宿主后执行 Rhino、STEP、STL 或输出中心；其他宿主上的问题组件不会阻断当前范围。
- 在装配检查器中可多选问题行。单击会选择对应控制点，“定位”缩放到联合范围，“删除组件”一次删除去重后的完整参数化组件，不删除宿主。
- 智能放置无法唯一找到咬合体时，先保留当前放置点，再点击后方封闭实体确认。后续长度修改继续使用该宿主。
- 需要恢复自动识别时，在维护中心选择“解除咬合确认”。

# 0.38.6 跟手放置与浮动窗口

1. 智能放置时移动鼠标只显示真实尺寸的紧固件本体和基础摘要；通孔、咬合孔和宿主角色在点击后统一精确识别。
2. 点击位置后若宿主或参数校验失败，本次不会写入组件，命令保持运行并显示具体原因。
3. 快捷编辑窗口中的长错误固定为单行省略；悬停可查看完整信息，读取、删除、取消和应用始终可见。
4. 点击主面板“更多”后，操作面板显示在活动视口上方居中，不需要从屏幕边缘拖回。

# 0.38.7 常驻更新与快捷操作栏

1. 主面板“应用更新”始终保持可点击；无选择时点击会提示选择控制点，不会修改上次读取的组件。
2. 选中一个或多个有效控制点后，可连续点击更新；每次都使用当前面板模板和当前 Rhino 选择。
3. 快捷编辑窗口底部使用 `读取｜取消｜应用｜删除` 单排按钮。
4. 首次点击“删除”后，最右按钮变为红色“确认删除”；2秒内再次点击才删除组件，不删除宿主。

# 0.39.0 主面板与快捷编辑

1. 主面板顶部“模板”显示将要创建或更新的参数；“目标”只显示Rhino当前选中的组件，不会覆盖模板。
2. 类型、规格和常用长度保持完整卡片网格；按“基础尺寸、装配方式、孔与切割”自上而下设置。
3. 预览和布尔开关按宿主角色排列。关闭倒角或架桥后，数值仍保留但不可编辑，重新开启即可继续使用。
4. 单选控制点后，快捷编辑窗始终显示高频参数和健康状态；错误不会遮挡底部操作。
5. 快捷窗使用`读取｜取消｜应用｜删除`：读取载入主面板，应用只提交小窗草稿，删除需要二次确认。
6. 底部八个图标按编辑、输出、检查分组，顺序和Rhino工具栏一致；放置与Rhino导出继续支持右键操作。
# 0.40.0 中英文界面切换

在主面板点击“更多”，搜索或打开“设置 → 语言”，选择：

- `自动（跟随 Rhino）`：简体中文 Rhino 使用中文，其他 Rhino 界面语言使用英文。
- `简体中文`：固定中文。
- `English`：固定英文。

切换后主面板、快捷编辑窗和已经打开的二级窗口会立即刷新，并保留输入、选择和未提交草稿。当前正在运行的 Rhino 命令继续使用启动时语言，下次运行采用新语言。侧边栏标题在重启 Rhino 后更新。

语言不会修改公共命令、组件参数、模板名称、备注、自定义标准件名称，也不会改名 3DM 中已有的插件图层、组、对象或材质。

# 0.40.1 文档健康与低干扰维护

1. 正常放置或更新后，插件会在后台检查控制点、宿主和派生对象引用；检查不会重新识别宿主或重新生成几何。
2. 文档正常时不显示健康提示。出现可确定修复的问题时，“目标”右侧显示`需维护 N`徽标，不覆盖放置或更新结果。
3. `需处理 N`表示存在待重绑或损坏组件；点击徽标可直接打开维护中心。
4. 关闭预览、关闭导出布尔以及图层、材质、组或可见性差异属于配置/显示状态，不计入组件故障。
5. 旧组件缺少快速健康清单时仍可正常更新和导出；下次更新或一键修复会自动补齐。
6. 完整布尔、碰撞、孔距和工具空间检查继续由装配检查器或导出预检按需执行。

# 0.40.2 快速小窗开关

主面板顶部的“快速小窗”开关始终优先完整显示。面板较窄、模板名称较长或使用英文界面时，模板工具栏会自动切换为两行；模板名称会省略显示，悬停可查看完整内容。关闭开关会立即隐藏快捷编辑窗，重新开启后继续按当前单选自动显示。

# 0.40.3 顶部模板工具行

顶部第一行是当前模板参数的唯一摘要；第三行不再重复显示规格和类型。工具行左侧保留收藏与模板菜单，右侧保留快速小窗开关。

# 0.40.4 后台健康状态入口

主面板不再持续显示后台健康徽标。需要查看文档健康状态时，使用组件导航器、底部“刷新/维护”、装配检查器或“更多”菜单。主动更新、导出或检查遇到错误时，主面板仍会显示本次操作的具体原因。
