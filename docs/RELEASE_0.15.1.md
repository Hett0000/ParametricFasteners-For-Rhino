# 参数化紧固件 0.15.1

## 修复

- 组件生命周期正式支持整体旋转和镜像，不再仅支持平移。
- 显式变换放置原点、局部 X 方向和螺杆 Z 轴，镜像后不会因 Rhino 重建右手平面而反转螺杆方向。
- 同步控制点、本体、隐藏切割体、宿主绑定和组件缓存；旋转或镜像后仍可读取、更新、统计和布尔导出。
- 带复制选项的镜像继续走独立副本管线，生成新的组件 ID、绑定 ID和对象 ID。
- 缩放、剪切等非刚性变换仍不改变规格参数，并给出明确提示。

## 兼容性

- 组件 schema 保持 v5。
- 插件 GUID、`RhinoMM.*` 元数据键、现有模型与旧命令保持兼容。
