# 参数化紧固件 0.21.1

## 工具栏深色模式

- RUI 工具栏升级为 Rhino 8 原生 SVG 图标格式。
- 工具栏标签和八个命令图标均内嵌独立的浅色与深色资源。
- 深色模式采用高对比浅灰线条，浅色模式继续使用深蓝灰线条。
- 图标由 Rhino 按当前主题和显示缩放实时渲染，不再依赖浅色 PNG 自动重着色。
- 保留原工具栏、宏和命令 GUID，升级后不会创建重复工具栏。

## 兼容性

- 插件版本升级为 0.21.1，组件 schema 保持 v8。
- 紧固件几何、宿主绑定、导出、统计和既有 3DM 数据不变。
- 需要重新启动 Rhino，使已加载的 RUI 库读取更新后的双主题图标。
