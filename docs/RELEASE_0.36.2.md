# 参数化紧固件 0.36.2：倾斜咬合孔倒角修复

## 修复内容

- 删除倾斜入口倒角的统一探测圆迭代放大算法，消除倾斜角增加时产生的正反馈和“包络未能稳定收敛”。
- 主孔入口只使用最终咬合孔半径测量，倒角小端固定在最深入口之后 `C`。
- 平面入口直接解析计算轴向 45° 锥体与实际 BrepFace 的闭合交线，保证最深侧倒角不少于设定值，浅侧自然变宽。
- 曲面及跨相邻面入口按 48 个径向方向执行有界根求解；任一方向缺少唯一入口区间时停止写入。
- 倒角锥口靠近实体边缘、入口重叠或达到 45° 物理临界时，显示具体几何原因，不生成残缺切口。

## 一致性

- 智能预览、组件切割对象、一键修复以及 Rhino、STEP、STL 导出均使用同一求解结果。
- 咬合孔的完全贯穿、L+1D 和 L+自定孔底保持不变。
- 旧 0.36.1 倒角组件无需迁移；实时导出使用新算法，一键修复或应用更新会重建派生倒角对象。

## 兼容性

- 插件版本：`0.36.2`
- 组件 schema：`v18`
- 模板 schema：`v3`
- 插件 GUID、组件 ID、绑定 ID和公开命令保持不变。
