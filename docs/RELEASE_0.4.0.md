# 参数化紧固件 0.4.0 实现说明

> 0.4.1 热修复：组件激活时按绑定角色读取参数，避免排在第一项的通孔绑定把咬合缩减量错误重置为 0；已覆盖 M6 创建后切换 M3 再次放置的流程。

## 编辑模型

- 规格、长度、孔径补偿、孔深和头部嵌入深度只写入面板草稿；只有“应用更新”会重建当前组件。
- “放置/绑定”始终创建新的组件，不会覆盖面板中已读取的组件。
- 不透明度、切割预览和导出布尔开关属于显示/导出状态，仍会即时保存。

## 控制点与选择

- 每个 schema v4 组件具有一个位于原放置面上的 Rhino Point，角色为 `ControlPoint`。
- 控制点位于 `参数化紧固件::控制点` 图层，是读取和编辑组件的选择入口。
- 紧固件代理体及切割模块被锁定并保留在稳定几何组中；控制点不加入几何组，也不参与 STL/STEP 导出。
- 放置命令排除所有带 `RhinoMM.ComponentId` 的对象，因此同一宿主、同一面可连续放置多个组件。

## 头部嵌入深度

- `0 mm`：头下贴放置面，头部完全露出。
- 正值：整颗螺丝沿轴向进入宿主，控制点仍留在原放置面。
- 等于实际头高：头顶与放置面齐平；面板“齐平”按钮按当前类型和规格填写该值。
- 大于实际头高：允许继续下沉，但不得超过头部宿主沿轴向的有效厚度。
- 螺母固定为 `0 mm`；杯头、沉头和六角头螺栓支持嵌入。
- `螺杆长度 + 2D` 的孔底为 `嵌入深度 + 螺杆长度 + 2 × 公称直径`；自定义盲孔仍从原放置面起算。

## 数据迁移

- 当前持久化版本为 schema v4，新增 `HeadEmbedDepth` 和 `ControlPointObjectId`。
- schema v1–v3 中已有头部切割宿主的组件迁移为当前规格的齐平深度；没有头部切割的旧组件迁移为 `0 mm`。
- 旧组件首次显式应用更新时创建控制点；组件 ID、宿主绑定、透明度、预览和导出布尔状态保持不变。
