# 参数化紧固件 0.35.2 发布说明

## 高频入口重排

- 快速编辑小窗新增“读取”，可放弃临时草稿并把组件已保存参数载入主面板。
- 主面板不再占用一个底栏位置显示读取按钮；“更多…”保留“读取选中组件参数”备用入口。
- 主面板与 Rhino 工具栏统一为：放置、更新、维护、放入 Rhino、STEP、统计、装配检查、更多。
- 放置与放入 Rhino 的左右键操作保持不变。

## 深色模式

- 装配检查器、维护与重绑、输出中心、标准件库、统计、批量预检、模板管理、交付信息、全局显示、进度窗口和快速小窗统一使用 Rhino 8 原生窗口主题。
- Rhino 运行期间切换浅色/深色主题时，插件语义卡片、状态色和动态区域同步更新。
- 表格、列表、输入框、下拉框、滚动条和按钮不再出现亮色孤岛。

## 版本信息

- “更多…”底部新增“关于参数化紧固件”。
- 关于窗口从程序集读取插件版本，并显示 Rhino 运行版本、组件 schema v17、模板 schema v2、用户库 schema v1。
- 支持一键复制完整版本信息。

## 兼容性

- 插件版本：`0.35.2`
- 组件 schema：`v17`（未变化）
- 模板 schema：`v2`（未变化）
- 用户库 schema：`v1`（未变化）
