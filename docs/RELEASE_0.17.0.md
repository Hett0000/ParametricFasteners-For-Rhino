# 参数化紧固件 0.17.0

## 新功能

- “显示与输出”增加“放入 Rhino 时包含紧固件实体”开关，默认关闭并跨 Rhino 会话保存。
- 开启后，“放入 Rhino”会同时输出与所选宿主关联的螺丝、六角螺母和热熔螺母普通 Brep。
- 紧固件实体随布尔成果一起动态预览、平移和成组，定位基点继续使用布尔宿主底面中心。
- 钢制紧固件自动使用共享的拉丝钢 PBR 材质，热熔螺母自动使用共享的黄铜 PBR 材质。
- 所有紧固件输出位于 `参数化紧固件::渲染紧固件` 图层，便于渲染时统一显示或隐藏。

## 可靠性

- 输出实体从控制点的最新组件参数实时生成，不依赖视口代理对象。
- 关联组件按组件 ID 去重；未关联所选宿主的组件不会混入成果。
- 取消放置不会创建图层或材质；写入失败会回滚对象、分组及本次新建的渲染资源。
- 开关关闭时保持 0.16.0 的布尔宿主导出行为；STEP、STL 和组件 schema v6 不变。
