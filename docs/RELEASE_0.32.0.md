# 参数化紧固件 0.32.0 发布说明

0.32.0 聚焦两项高频效率问题：一次创建多个紧固件，以及在大型 Rhino 文档中快速找到、检查和处理参数化组件。

## 新增：点集批量放置

- 支持 Rhino Point、点云、开放曲线起终点及圆/圆弧中心。
- 使用主面板当前不可变模板，每个点独立识别实体面、方向、宿主和切割关系。
- 点位必须严格位于有效封闭实体面上，不会静默投影到其他位置。
- 创建前提供可定位的有效、警告、失败预检。
- 默认全有或全无；可显式跳过失败点。
- 每颗紧固件保持独立组件 ID，整批创建只产生一次 Undo。
- 主面板和 RUI 工具列的“放置”左击仍为智能连续放置，右击启动批量放置。

## 新增：组件导航器与问题中心

- 新增独立 Rhino 停靠面板和 `ParametricFastenersNavigator` 命令。
- 可按类型、规格、装配方式、宿主、宿主图层和健康状态筛选。
- 单击定位控制点、双击缩放；筛选不会加载或覆盖主面板模板。
- 筛选结果可直接选择、应用当前模板、统计以及导出 Rhino/STEP/STL。
- 即时状态包括待重绑、参数无效、导出关闭、预览隐藏和数据损坏。
- “深度检查”按需在内存中执行真实布尔验证，可取消且不修改文档。

## 性能基础

- 新增文档级 RTree 宿主空间索引。
- 智能鼠标拾取、轴向宿主扫描和点集放置先做空间过滤，再执行精确几何求交。
- 对象变化、文档切换和 Undo/Redo 后索引自动失效并按需重建。
- 同一位置的动态代理体和切割预览使用有上限的规范化几何缓存，参数或宿主修订变化后不会复用旧结果。
- 3DM 元数据仍是唯一持久化事实来源，运行时索引可以安全丢弃和重建。

## 兼容性

- 组件 schema 保持 v16，不修改已有 3DM 组件数据。
- 插件 GUID、组件 ID、绑定 ID、`RhinoMM.*` 元数据键和旧命令保持兼容。
- 左击智能放置、经典放置、快速编辑、批量更新、统计和三类导出行为保持不变。

## 主要命令

| 命令 | 作用 |
| --- | --- |
| `ParametricFastenersBatchPlace` | 选择点位来源，预检并批量创建组件 |
| `ParametricFastenersNavigator` | 打开组件导航器与问题中心 |

## 验证范围

- 核心与插件源码回归测试。
- Release 构建。
- RUI 左右键宏和嵌入资源生成。
- Rhino `Compat.exe` 兼容检查。

Rhino 内实际交互仍应重点复核：复杂重合面点位、多视口定位、数百组件筛选、长时间深度检查取消，以及批量创建后的 Undo/Redo。
