# 参数化紧固件 0.14.1

## 界面

- 将重复的“孔设置”和“放置切割预设”合并为“孔与切割”。
- 编辑组件时可在“当前组件”和“放置预设”之间切换；新建状态直接显示放置预设。
- 当前组件、批量模块模板和跨会话放置预设保持独立，切换模式不会互相覆盖。
- 数值框、配合下拉框和孔深选择使用紧凑语义宽度并左对齐，尾部保留弹性空白。
- 340 DIP 以上合并字段行，窄面板自动换行；内容区不设置横向滚动尺寸。
- “补偿切割模块”更名为“宿主切割模块”，只在当前组件模式显示。

## 行为

- 放置预设模式禁用“应用更新”，并将“放置/绑定”作为主操作。
- 当前组件模式只修改组件草稿；放置预设模式只保存跨会话预设。
- 读取已有组件不会覆盖放置预设；完成放置或读取后自动返回当前组件模式。
- 导出在放置预设模式下使用文档中已保存的组件参数，不把预设误应用到已有组件。

## 兼容性

- 组件 schema 保持 v5。
- 插件 GUID、组件 ID、`RhinoMM.*` 元数据、旧命令和既有 3DM 文件保持兼容。
