# 参数化紧固件 0.26.1

## 修复

- 修复“只咬合”组件导出 Rhino、STEP 或 STL 时可能不生成螺丝孔的问题。
- 导出前在内存中重新复核唯一咬合宿主，不依赖旧预览切割体。
- 从普通多宿主组件切换为“只咬合”时，预览和导出布尔状态从咬合模块继承，不再误用通孔模块状态。

## 界面

- 响应式布局增加 300、340、420 DIP 分级，280 DIP 下类型卡片使用三列，孔参数至少保持两列。
- “追加深度”与咬合孔深度下拉框拆行，移除最主要的横向溢出来源。
- “只咬合”开启时隐藏通孔模块，仅显示当前有效设置。
- 缩短架桥摘要、卡片内边距和上下文切换宽度，减少纵向滚动距离。

## 兼容性

- 组件 schema 保持 v12。
- 插件 GUID、命令、组件 ID、绑定 ID和`RhinoMM.*`元数据键不变。
