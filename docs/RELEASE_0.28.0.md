# 参数化紧固件 0.28.0

## 新功能

- 六角螺母增加“普通｜尼龙防松”样式。
- 尼龙防松螺母支持 M2、M2.5、M3、M4、M5、M6、M8、M10、M12。
- M3–M12 使用 GB/T 889.1-2015 兼容外包络；M2、M2.5 标记为 DIN 985 工程扩展，界面提示打印前核对实物。
- 防松螺母代理体使用全高六角外形和简化尼龙嵌件提示，安装切割使用不含中心孔的全高六角盲槽。

## 更新与兼容

- 普通/防松样式切换支持 0、全埋和自定义嵌入深度语义。
- 统计和 Excel 分开汇总两种螺母，明细增加“螺母样式”和“尺寸标准”。
- 组件 schema 升级为 v15；旧六角螺母自动迁移为普通样式，组件 ID、绑定和旧命令保持不变。

## 验证

- 覆盖 M2–M12 尺寸、打印补偿、迁移、模板更新和统计工作簿测试。
- 回归智能放置、批量更新、复制变换以及 Rhino、STEP、STL 实时切割链路。
