# 参数化紧固件 0.30.0

## 第一阶段快速编辑

- 单选有效控制点后约 250 ms 自动显示视口快速编辑器；窗口随控制点定位，离开视口、多选或进入其他 Rhino 命令时自动隐藏。
- 快速编辑器使用独立草稿，可编辑当前类型最常用的尺寸和装配参数，并在提交前显示半透明本体与切割轮廓；不会覆盖主面板模板。
- 新增 `ParametricFastenersEditHandles`，通过点击手柄、定位、再次点击确认的方式修改长度、嵌入深度、螺母末端露出量和局部方向。
- 参数手柄支持常用长度 0.5 mm 捕获范围、嵌入 0/齐平或全埋、螺母露出 0/2 mm，以及 15° 方向吸附。

## 模板与历史

- 主面板增加紧凑模板栏，保存最近 5 个成功模板和最多 50 个收藏模板。
- 收藏模板支持重命名、复制、排序、删除及 JSON 导入/导出；模板只保存可复用参数，不保存组件、宿主、绑定或坐标。
- 新增 `ParametricFastenersRepeatPlace` 和 `ParametricFastenersRepeatUpdate`；重复操作使用历史快照，不修改当前面板模板。
- 模板库使用独立 schema v1 和 Rhino 用户级设置保存；损坏数据会备份并回退为空库，不影响插件加载。

## 一致性与兼容

- 主面板、快速编辑器、参数手柄及重复更新共用几何准备和组件更新协调器，统一执行宿主重识别、校验、本体/切割体构建、一次 Undo 提交和选择恢复。
- 插件版本升级为 `0.30.0`，3DM 组件 schema 继续使用 v16；现有组件、GUID、绑定、统计及导出格式无需迁移。
