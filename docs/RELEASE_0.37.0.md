# 参数化紧固件 0.37.0：上下文编辑与交互收敛

本版本不增加新的紧固件类型或持久化参数，重点统一组件编辑入口和视口表达。

## 主要变化

- 单选控制点后显示上下文编辑条。编辑字段、参数手柄、翻转和预检共享同一个 `ContextualEditSession`，点击“应用”前不会修改 Rhino 文档。
- 多选控制点后显示批量摘要条，可直接应用主面板模板、检查装配或开启剖切。
- 主面板固定显示“创建模板”和“选择目标”；选择对象不再切换参数来源。
- 新增 `ParametricFastenersSectionView`，在视口中以角色颜色显示宿主截面、通孔、咬合孔、承座和安装槽，不创建文档对象。
- “更多…”升级为可搜索的分组操作面板，支持方向键、Enter 和 Esc。

## 兼容性

- 插件版本：`0.37.0`
- 组件 schema：`v19`
- 模板 schema：`v4`
- 用户标准件库 schema：`v1`
- 现有组件、公开命令、工具栏和导出格式保持兼容。
