# 参数化紧固件 0.36.1：咬合孔入口直线倒角

## 新功能

- 第一种装配方式“螺纹咬合”增加可选的咬合孔入口倒角。
- 默认关闭；新建预设默认保留 `C0.50 mm`。
- 垂直入口生成标准 45° 直线锥口：小端为最终咬合孔径，大端为最终孔径加 `2C`。
- 倾斜或曲面入口根据完整切口圆周的实际入口包络延长锥口，最深侧仍保证设定 C 值。

## 一致性与安全

- 倒角仅作用于 `螺纹咬合`模式的咬合宿主；通孔、只咬合、螺母固定和螺母类组件不受影响。
- 倒角不会改变完全贯穿、L+1D 或 L+自定值的原孔底位置。
- 入口重叠、接近切向、包络不可靠或宿主厚度不足时，操作会在写入前停止，不留下部分组件。
- 智能摆放、更新、修复、Rhino、STEP 和 STL 使用统一切割准备结果。

## 数据兼容

- 组件 schema 升级为 `v18`；旧组件迁移后倒角保持关闭，原几何不变。
- 模板 schema 升级为 `v3`；最近使用、收藏、重复放置和重复更新会保存倒角参数。
- 插件 GUID、组件 ID、绑定 ID和公开命令保持不变。
