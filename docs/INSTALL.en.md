# Parametric Fasteners 0.40.4 — Offline Installation

## Recommended method

1. Close every Rhino 8 window.
2. Extract the complete offline ZIP to a stable local folder.
3. Run `Install Parametric Fasteners.cmd` if supplied, or run the packaged installer as described by the Chinese companion document.
4. Start Rhino once after installation.
5. Run `ParametricFasteners` or `ParametricFastenersMore`.

You can also install the local `.yak` through Rhino Package Manager. The plug-in becomes available after Rhino is fully restarted.

Do not manually load the RHP from a temporary extraction directory, Downloads, a USB drive, or a folder that will later be moved.

## Troubleshooting

Run the diagnostic command file included in the offline package. It checks the installed Yak version, plug-in files, dependencies, Windows download blocking, Rhino registration, and key commands without exposing private document content.

The public plug-in commands remain English in every interface language so Rhino macros and scripts stay stable.
