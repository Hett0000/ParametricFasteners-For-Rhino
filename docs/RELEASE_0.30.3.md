# 参数化紧固件 0.30.3

## 快速编辑标题

- 快速编辑小窗标题增加紧固件短类型，例如`杯头 M3X20`、`沉头 M4X30`、`防松螺母 M5`和`热熔螺母 M3X5`。
- 修改规格、长度或普通/防松样式时标题同步刷新，窗口仍保持252 DIP紧凑宽度。
- 短类型名称由共享标签服务提供，主面板摘要与快速编辑器保持一致。

## Rhino侧边栏图标

- 为“参数化紧固件”面板增加专用螺丝定位图标，不再以空白标签显示。
- 图标使用透明背景和兼容浅色/深色侧边栏的蓝色、橙色配色。
- 内嵌ICO包含16、24、32、48像素帧，并通过Rhino 8资源式面板注册接口加载。

组件schema继续使用v16，几何、绑定、导出和现有3DM数据无需迁移。
