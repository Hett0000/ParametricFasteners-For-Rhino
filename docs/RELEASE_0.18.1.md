# 参数化紧固件 0.18.1

## 修复

- 热熔螺母参数区改为紧凑的“孔径 / 深度”和入口导角摘要，完整计算公式收纳至 Tooltip。
- 参数区按实际可用宽度约束，窄面板自动将热熔参数切换为单列，不再由长说明触发横向滚动。
- 紧固件本体和切割模块改为复用两种文档级显示材质，复制组件不再按组件 ID 创建新材质或贴图资源。
- 首次复制旧组件时可原位提升旧显示材质；刷新和全局透明度操作会迁移旧引用，并仅清理没有任何对象使用的旧插件材质。

## 兼容性

- 组件 schema 保持 v7。
- 插件 GUID、组件 ID、`RhinoMM.*` 元数据键、旧命令及现有 3DM 文件保持兼容。
- 拉丝钢和黄铜 PBR 渲染导出材质不受显示材质清理影响。
