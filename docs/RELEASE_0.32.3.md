# 参数化紧固件 0.32.3 批量预检布局优化

0.32.3 优化点集批量放置的预检窗口，使少量和大量点位都能高效查看与确认。

## 改进

- 窗口改为“固定摘要、弹性表格、固定操作栏”，创建与取消按钮不再被纵向拉伸。
- 初始高度根据点位数量自动调整，更多点位只在表格中纵向滚动。
- 摘要分离显示有效、警告和失败数量，并使用兼容深浅色主题的状态色。
- 表格列随窗口宽度重排，识别结果占用剩余空间并预留滚动条宽度，避免横向滚动。
- 选中行会显示紧凑详情，完整坐标精度和原因可通过悬停提示查看；单击定位和双击缩放行为保持不变。
- 无失败项时直接显示可创建数量；存在失败项时必须明确勾选“跳过失败点”才能继续。

## 兼容性

- 批量预检、一次 Undo 和全有或全无提交策略保持不变。
- 组件 schema 保持 v16，现有 3DM 文件无需迁移。
