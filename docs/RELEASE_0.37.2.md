# 参数化紧固件 0.37.2：智能放置轻量预览与性能优化

## 主要变化

- 悬停阶段不再生成完整轴孔、沉孔、倒角或安装槽 Brep，也不执行布尔预检。
- 新增命令级宿主 RTree，前表面按宿主精确求交，轴向扫描仅处理有限线段附近候选。
- 虚拟紧固件本体使用局部坐标 LRU 缓存，鼠标移动时只复制并变换；复杂切割以圆、线、锥台、六角轮廓和短标签表达。
- 鼠标输入按约 33 ms 合并；动态绘制回调不再识别宿主或准备几何。
- 单击时重新捕获最新参数与 Osnap 上下文，执行一次完整准备，并直接提交已经准备的几何。
- 精确结果与轻量预览不一致、宿主失效或文档修订变化时零写入，命令保持运行。

## 兼容性

- 组件 schema 保持 v19。
- 模板 schema 保持 v4。
- 紧固件几何、宿主识别规则、公开命令和导出精度不变。

## 验证重点

- 大量宿主文档中的自由面拾取、Osnap 和连续放置响应。
- 放置期间修改规格、长度及切割参数后的预览同步。
- 最终组件、Rhino、STEP 和 STL 继续使用相同的精确几何规则。
