# 参数化紧固件 0.8.0

## 类型与导出

- 紧固件类型改为四张中文卡片；M 规格和常用长度卡片保持不变。
- 面板提供独立的“放入 Rhino”和“导出 STEP”按钮，STL 收入“更多…”菜单。
- 存在未应用草稿时，导出前先事务式更新组件；更新失败不会启动导出。

## 咬合孔深度

- 新增“螺杆长度 + 1D”，孔底为嵌入深度、螺杆长度与一倍公称直径之和。
- L+1D、L+2D 和自定义盲孔严格止于计算孔底，不再在封闭端增加布尔余量。
- 计算深度超过宿主厚度时允许自然贯穿，并在模块与导出消息中提示。

## 安全移动

- Rhino Move 删除旧对象并生成新 ID 时，控制点不再触发组件级联删除。
- 单独移动控制点会同步移动整颗组件；宿主与组件共同移动时自动更新宿主绑定 ID。
- 移动完成后更新放置坐标、代理体、控制点、切割体 ID、组关系和编辑缓存。
- 隐藏的切割预览也会执行相同平移，Undo/Redo 由当前 Rhino Move 命令统一管理。

## 兼容性

- 持久化 schema 继续使用 v5；枚举按字符串保存，无需迁移旧组件。
- 插件 GUID、组件 ID、`RhinoMM.*` 元数据键及旧命令保持兼容。
