# 参数化紧固件 0.40.4 离线安装

安装后可在“更多 → 设置 → 语言”选择自动、简体中文或 English。侧边栏标题会在重启 Rhino 后跟随所选语言更新。

## 推荐安装

1. 保存工作并完全关闭 Rhino 8。
2. 将整个离线安装 ZIP 解压到本地文件夹；不要只打开压缩包直接运行。
3. 双击 `安装参数化紧固件.cmd`。
4. 安装成功后启动 Rhino 8 一次，等待 Package Manager 完成插件注册，再运行 `ParametricFasteners`。
5. 在“更多 → 关于参数化紧固件”中确认安装方式为 `Yak`、状态为“安装正常”。

安装器使用 Rhino 自带的 Yak，将插件复制到当前 Windows 用户的稳定包目录。Yak是插件注册的唯一来源；安装器不会额外写入简略插件注册。无需管理员权限，也无需网络。

## 重要说明

- 不要从压缩包临时目录、U 盘、Downloads 临时解压目录直接选择 RHP 安装。
- 更新不会删除模板、收藏、全局显示设置或已有 3DM 组件。
- 如果提示 Rhino 正在运行，请彻底退出 Rhino 后重试。
- 如果提示系统级旧注册冲突，请先在 Rhino `PluginManager` 中卸载旧版；仍无法清理时需由管理员移除旧的系统级安装。
- 原始 `artifacts/plugin` 目录只用于开发调试，不是正式用户安装包。
- 在 Rhino 的 Package Manager 中直接选择 Yak 也受支持，但新命令只会在完全重启 Rhino 后注册；当前安装会话中显示“未知命令”属于正常现象。
- 重启后仍找不到命令时，运行`诊断安装.cmd`并保留生成的诊断文本。

## 手工验证

安装后连续重启 Rhino，以下命令应始终可用：

- `ParametricFasteners`
- `ParametricFastenersPlace`
- `ParametricFastenersApplyUpdate`
- `ParametricFastenersAssemblyInspector`
