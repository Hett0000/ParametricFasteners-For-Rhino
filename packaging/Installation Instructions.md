# Parametric Fasteners 0.40.4 Offline Installation

Close Rhino 8, extract the entire archive, and run the supplied installer. Alternatively, install the local Yak with Rhino Package Manager. Fully restart Rhino once before running `ParametricFasteners` or `ParametricFastenersMore`.

Do not install the RHP directly from a temporary folder, Downloads, or removable media. Use the diagnostic script included in the package if commands are unavailable after restart.
